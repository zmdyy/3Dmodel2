# 3D 交互模型作品集

这是一个面向教学演示的静态作品集入口。每个 3D 案例保持为独立 HTML，主页只负责检索、分类、展示与按需加载，因此扩展到更多案例时不会让首页同时启动大量 WebGL 场景。

## 目录

```text
index.html              # 作品集主页
catalog.js              # 案例清单：标题、分类、标签、路径等
models/                 # 每个独立 3D 交互 HTML
shared/                 # 多个案例共用的交互/视觉规范
shared/current-flow-style.js  # 统一电流箭头的形式、大小、密度与速度
scripts/add-model.py    # 后续新增案例的整理脚本
```

## 后续新增案例的标准流程

1. 保留原始 HTML，不直接把代码合并进 `index.html`。
2. 给案例分配稳定的英文 `id`，文件统一保存为 `models/<id>.html`。
3. 若案例内嵌 Three.js r144，先替换为 `shared/vendor/three-r144.min.js` 本地公共引用，避免每个文件重复约 600 KB 的库代码。
4. 在 `catalog.js` 新增一条元数据，包括标题、分类、简介、标签、文件路径、符号与主题色。
5. 打开主页检查：卡片可检索、分类正确、点击后可在作品集内交互、返回后不残留 WebGL 场景。
6. 提交到 GitHub。以后案例数量较多时，可继续在不改变主页结构的前提下增加分类、年级或章节字段。

也可使用辅助脚本：

```bash
python scripts/add-model.py ./新案例.html --id new-demo --category 电学元件 --tags 电阻,结构
```

## 钱塘江大桥 · 气压沉箱施工

- `models/qiantang-caisson.html` 以1930年代钱塘江大桥基础施工为背景，先表现沉箱浮运定位并落到木桩群，再进入压气排水、下部挖泥与上部筑墩同步进行、封底承重等阶段。
- 沉箱按史料中的约 18 m × 11 m × 6 m、约 600 t 建立教学尺度；九个桥墩的木桩工程共1440根，页面用密集单墩桩群表达承托关系，但具体排布不宣称工程图级复原。
- 默认采用正对剖面的正交视图，可切换自由观察；手动降低供气表压时，根据 Δp≈ρgh 显示作业室进水。施工下沉不简化为“放气下沉”，而是明确提示自重、浮力、土体阻力与挖泥施工共同作用。
- 人员气闸／竖井、供气管和出泥通道尚缺原工程图级细节，因此均标记为教学示意。沉箱封底后保留在地下，传力箭头显示墩身—沉箱—木桩群—土体的荷载路径。
- 仓库版复用本地 `shared/vendor/three-r144.min.js`，不依赖 CDN。资料参考茅以升相关建桥回忆、西南交通大学校史资料、浙江省档案馆与央视《国家记忆》相关内容。

## 天宫空间站：结构观察与天地通信

- `models/communication-satellite.html` 将地球、地面站、同步卫星和中国空间站放在一个通信场景中；“近看空间站”只改变观察尺度，详细几何由 `shared/tiangong-model.js` 建立。
- 依据用户提供的三舱参考图及中国载人航天工程办公室资料，重建天和的小/大柱段、球形节点舱、问天气闸、梦天货物气闸与舱外载荷面；加入对接环、隔热表面、扶手、设备盖板、天线馈源、四片双毯面柔性太阳翼及大小机械臂。
- 国旗采用 1536 × 1024 高清程序纹理，按 3:2 比例和标准五星布局绘制，四颗小星各有一个角尖指向大星中心。贴片几何沿圆柱舱壳曲面贴合，预留空白表面，避开扶手与设备盖板；“国旗近看”可聚焦所选舱段的标识。
- 舱段长度按天和 16.6 m、实验舱约 17.9 m 和舱体直径 4.2 m 建立。外部附件、局部比例与机械臂姿态为教学简化，不是工程 CAD。
- 可点击模型或部件列表查看功能、聚焦放大、俯视 T 字构型、分解舱段、转动太阳翼、开关标注及来访飞船。模型用材质批次合并几何体，完整结构约 80 次绘制；没有以图片代替 3D 模型。
- 两艘神舟、一艘天舟及核心舱小太阳翼是参考构型示例，界面明确说明其不代表当前停靠和外部配置。分解视图用红线区分永久连接、蓝线区分来访停靠。
- 所有天体使用同一时钟：地球与地面站一起自转，GEO 同向、同周期公转，空间站以约 1436.068 / 92 的角速度比绕行。可切换太空视角和随地球观察，也可暂停整个系统。结构近看仍保留系统时钟。
- 地面抛物面凹口朝目标，馈源位于焦点（f = R² / 4d），三根支撑杆从正向碗沿连接馈源。目标低于地平线时，天线向上待机。可近看天线和金色指向箭头。
- 切换“地面站间通信”与“空间站天地通信”只选择高亮路径与跟踪目标，所有航天器继续在同一场景显示。地平线判断使用球面站点，不以放大天线的高度扩大可见范围；所有可见信号段还进行球体遮挡检查。轨道间距压缩、模型尺寸放大，覆盖时间与中继调度不是实况预测。
- Three.js 和 Earth / cloud 纹理使用本地资源，模型不依赖 CDN。地球纹理源自 `mrdoob/three.js` r144 的 `examples/textures/planets/`；Three.js 的 MIT 许可见 `shared/vendor/THREE-LICENSE.txt`。
- 资料：CMSE [天和核心舱](https://www.cmse.gov.cn/xwzx/zhxw/202105/t20210507_47814.html)、[实验舱与 T 字构型](https://www.cmse.gov.cn/xwzx/202211/t20221107_51360.html)、[机械臂](https://www.cmse.gov.cn/xwzx/202401/t20240108_54902.html)、[天地通信](https://www.cmse.gov.cn/xwzx/202301/t20230103_52072.html)；用户提供的[维基百科构型参考](https://zh.wikipedia.org/zh-cn/天宫空间站)。

- 天线与同步轨道原理：NASA [抛物面天线](https://www.nasa.gov/general/what-is-an-antenna/)、ESA [Geostationary orbit](https://www.esa.int/ESA_Multimedia/Images/2020/03/Geostationary_orbit)。

## 海市蜃楼：清晰虚像与物体观察

- `models/mirage.html` 同步独立新版中的光线实线箭头、虚线反向延长线和像点标记。上蜃物体移远并按地平线下的可用高度同比例放大，删除礁石和坡地球形底座，建筑直接落在薄地表上，地表不进入虚像克隆；下蜃卡车、树与倒像共用放大后的真实几何，光路从更新后的车顶锚点求解。
- 实物建筑采用深色粗糙石材与灰色屋顶、树木采用深绿色叶片纹理和棕色树皮；虚像材质在实物修改前独立克隆，保持上版外观。虚像保留塔顶、窗、车身、玻璃、轮胎和树冠的独立材质，主体不透明度提高至 96%，取消白色自发光；在空气层之后绘制并保留自身深度关系，避免发白且轮廓清楚。

## 凹透镜成像规律

- `models/concave-lens.html`：与凸透镜案例保持一致的光具座、物像高度测量、遮挡及自动演示操作，支持组合、仅 2D、仅 3D 三种视图。
- 对实物使用负焦距薄透镜公式，始终成正立、缩小虚像；靠近时像变大并靠近透镜，远离时像变小并趋近物方焦点。光屏无法承接虚像。
- 平行入射光的反向延长线经过物方焦点 F；过光心光线保持实线；指向右焦点 F′ 的入射光附带向前辅助虚线，折射后平行射出，不绘制其向左水平反向延长线。
- 透镜厚度为增强辨识的教学示意，不参与成像计算；自动演示经过物方焦点减速，但不发生像的性质反转。
- 复用仓库本地 Three.js r160 与共享鼠标操作规范；首页封面由本案例实际 3D 场景截取。

## 阿基米德原理 · 排水称重
