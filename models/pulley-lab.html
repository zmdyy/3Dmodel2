4. 课堂计算口径

依用户要求，忽略紧凑轮组斜绳角度的小幅变化，计算按承重绳平行近似。同一装置与参数下拉力恒定；竖直拉绳及紧凑轮组采用S=nh，单动滑轮主动斜拉采用下文的投影位移关系；主读数、图像、表格与CSV统一采用这一口径。

G = m物 g；g = 10 N/kg
S = nh
理想模式：F = G/n，η = 100%
W有用 = Gh
W总 = FS
η = Gh/(FS)

自重与轴阻模式中，动轮组质量可在0～3 kg间调节，滑条与数值输入同步。它指全部随物体上升的轮片、轮轴与轮架总质量，不含钩码，也不包括固定轮组；单轮、多轮均只计一次总质量。定滑轮模式不计动轮组质量。理想模式忽略该参数。

每轮恒定轴阻力矩τ为0～0.08 N·m。按轮半径、绕向和初始提升转向计算各相邻绳段的恒定张力差：

T出 − T入 = τ sign(ω)/(σR)
Σ 承重段 T段 = (m物 + m动)g
F = 自由端绳段张力
W提轮组 = m动 gh
W轴阻 = FS − Gh − m动 gh

此处不随h更新斜绳分力和张力；轴阻采用恒定等效阻力。因而相同轮组、质量及轴阻下，改变提升高度不会改变效率；增加钩码重力通常提高效率，增加动轮组质量降低效率。h=0的效率显示为同条件下的单位提升功比，不对0/0运算。

三维外观仍用有限半径精确公切线保持绳贴轮槽及外观绳长，轮转角按外观绳路计算。其实际绳端行程与课堂读数nh存在少量差别，二者不作为精确工程动力学等价；切点校验显示的是外观几何，探究数据采用上述课堂模型。S尺寸线用实际初末位置作视觉参考，数值为nh。h尺寸线来自重物最低点初末位置。尺寸端部使用短横线，不用力箭头。

力的起点以实心点标出，方向用箭头，大小以牛顿数值与统一线性比例箭头长度表示。覆盖绘制使力不被实体遮住，作用点不为排版而移到空中。

6. 接触算法与动画

相邻圆心差距离D、方向角φ，绕向σ，半径Ri、Rj；绳头点的半径取0：

β = φ + asin((σi Ri − σj Rj)/D)
t = (cosβ, sinβ)
n右 = (sinβ, −cosβ)
Qi = Ci + σi Ri n右
Qj = Cj + σj Rj n右

切点满足距圆心为R且半径垂直直绳；接触圆弧按绕向连接。以初始外观总长L0为基准调整自由直段，保持有限轮径外观绳长。轮片转角同时计入切点角变化和从固定绳头量起的材料路径变化：Δθ=Δα−Δℓ/(σR)。绳上标记沿材料路径运动。

拉绳交互按h=S/n反求高度。定滑轮目标高度为0.05～0.80 m，其余基础轮组为0.05～0.60 m，达到目标自动暂停。改变质量、轴阻、装置、拉绳方向等条件后回到初位，已有记录保留。匀速提升采用准静态计算，忽略松绳、自由摆动、弹性与转动惯量。

9. 验证结果

5490组计算状态通过检查：五种绳路、61个高度、三种钩码质量、三种动轮组质量、理想及自重轴阻模式。验证S=nh、恒定拉力、FS功的分解、竖直平衡和约束力矩、效率随两种质量变化的趋势与高度无关性。外观最大绳长残差约1.8×10⁻¹⁵ m，切线正交残差约4.5×10⁻¹⁶ m；这些是程序一致性检查，不是器材精度。

真实Three.js几何结合模拟DOM与渲染器验证五种结构切换、标签独立显示、受力对象隔离、比例尺与作用点、摄像机跟随、展开复原，以及四项任务的控制量锁定、条件改变复位、质量影响、记录、答案揭示与图像。软件投影核对了模型构图。尚未进行实际浏览器GPU画面、文字排版及拖动触屏手感验收。

10. 新增：80 cm行程与动滑轮斜拉

定滑轮自主探究默认目标高度和滑条最大绳端行程均为80 cm。其他轮组保持最多60 cm提升高度；控制变量任务中目标高度仍按设置保留，避免切换装置时破坏控制量。

单动滑轮的自由端角度为相对竖直向上的−60°～60°，固定侧绳竖直。固定角度时，每个承重段张力的方向参与竖直平衡；器材自重和轴阻仍可开启。理想无质量模型：

α = 自由侧绳与竖直向上的夹角
F = G/(1+cosα)
S∥ = (1+cosα)h
W总 = F S∥

自由端同时横向和竖向移动，S∥是沿当前拉力方向的位移投影累计值，不是手柄轨迹弧长。恒定角度时，两者满足虚功和实际绳长约束。三维标尺用垂直于拉力方向的虚线将实际自由端投影到对应的测量端点。表格、CSV与图像均使用同一投影口径并保存角度；角度改变会复位。0°时F=G/2，60°时F=2G/3。省力与距离任务自动恢复0°；紧凑轮组继续使用平行绳简化。

11. 新增：多边形轮与等效杠杆

独立入口“拓展·滑轮与杠杆”。轮形有圆、正三角、正四边、正五边、正六边和正十五边，统一外接圆半径0.60 m。金属轮体由有中心孔的三层挤出体构成，两侧轮缘之间保留周向绳槽；轮轴不随轮片转动，后侧轮架连接载荷。绳路沿真实多边形下侧边界，折点用绳半径球面连接，未沿虚构圆周绕绳。

拓展忽略轮体质量、轴阻与惯性，G固定30 N。两侧绳竖直，左侧绳的上端固定。轮体沿左侧静止绳无滑动，允许轮心横向微移。以相对轮心坐标最左顶点rO、最右顶点rA为接触位置，a=−rO.x、b=rA.x。轮心横坐标为a，纵向升高为a关于转角θ的积分；积分按最左接触顶点的切换分段解析计算。由此左侧绳所在竖线固定为x=0，轮心瞬时速度满足固定侧接触点无滑动。

O = 左侧静止绳当前接触位置（瞬时等效支点）
C = 轮心
A = 自由侧绳接触位置
l1 = a+b（O到右侧力作用线的垂直距离）
l2 = a（O到重物作用线的垂直距离）
F l1 = G l2
F/G = a/(a+b)
T固定 = G−F

O、C、A为圆点，无支点指示箭头。F、G、T固定按同一比例画在各自作用位置，显示作用线与垂直力臂，可关闭等效杠杆叠加或力的显示。圆轮a=b=R，故动力臂2R、阻力臂R，F=G/2；多边形轮的a、b随转角改变。接触边与绳共线的临界姿态取增大转角一侧的支点极限，不能把整条接触边或轮轴中心直接当成恒定支点。

左侧直段、下方包绕边界和自由端直段的总绳长保持不变，由长度反求手柄位置。F乘手柄竖直微位移等于G乘轮心竖直微位移，满足虚功关系。轮体转角0～120°，可拖动、每次1°单步或慢速播放，到120°停止。五种多边形和圆轮共享相同材质基准，正十五边形用于观察向圆轮逼近。

新增验证：7200个转角状态核对轮形支撑点、分段升高积分、静止侧瞬时无滑动、绳长、杠杆平衡和虚功；五个拉绳角度核对单动滑轮拉力、竖直平衡、投影位移与功。瞬时虚功残差低于1.8×10⁻⁷ m/rad，无滑动速度系数残差低于3.1×10⁻⁷ m/rad。交互逻辑核对80 cm端点、角度入表、六种轮形、拓展进出及复位。实际浏览器GPU显示与手势尚未验收。

杠杆力臂定义参考OpenStax《University Physics Volume 1》10.6 Torque：https://openstax.org/books/university-physics-volume-1/pages/10-6-torque 。多边形轮的接触、积分与虚功关系为本拓展自行推导并通过数值一致性检验。
