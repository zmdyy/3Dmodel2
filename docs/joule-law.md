# 焦耳定律三维实验

- 入口：`models/joule-law.html`，可单独下载后双击离线运行。
- 比较电阻：5 Ω 与 10 Ω 电阻丝串联，同电流下右侧产生的热量较多。
- 比较电流：两容器内部电阻丝均为 5 Ω，右侧容器外并联 5 Ω 电阻丝，两个支路并联组合与左侧串联，左容器内电流为右容器内电流的两倍。
- 变速作用于加热进程及粒子运动，不改变热效应的比较关系。粒子数量与大小只改变显示效果。
- U 形管液柱伸缩时底端固定，连接侧下降、开口侧上升。水平对比线跟随开口侧液面，可切换到正视读数。
- 网格、世界变换与 PBR 材质按两种模式分别和原始 GLB 全量比对，通过；Gzip 解压结果与合并 GLB 逐字节一致。
- 模型中保留 166 组共用根部件，独特网格从原两文件共 475 个去重到 84 个；合并后 HTML 约 2.62 MB，比前版减少约 73%。
- 光照为 Three.js 中重建的柔光、AgX、反射环境与阴影，不能等同于 Blender Cycles 离线路径追踪。
- 热量进程、粒子速度及液面变化是教学定性示意，未实测标定，不能作为温度或焦耳热的测量工具。
