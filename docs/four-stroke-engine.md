# 单缸四冲程汽油机

- 入口：`models/four-stroke-engine.html`；脚本：`shared/four-stroke-engine.js`；已确认 Blender 模型导出为 `assets/models/four-stroke-engine.glb`。
- 教材 T 型侧置气门结构，非某款量产发动机复刻。缸径60 mm、行程60 mm、连杆中心距100 mm。曲轴转两圈完成一次循环，凸轮轴转一圈。模型尺寸为教学比例，不是制造CAD。
- 使用Three.js r165公共模块，无外部CDN依赖。保留原模型钢、铝、青铜及涂装铸铁PBR参数，AgX色调映射；网页补微表面纹理、环境反射和接触阴影。
- 鼠标遵循公共约定：左键同向旋转、右键或Shift+左键平移、滚轮缩放。提供整体、气缸正视与气门局部视角。
- 0°—720°可拖动时间轴，每180°一段。支持完整循环、单冲程循环、慢放、下一冲程、复位；单冲程循环直接回到起点，不倒放。重播提示位于下方控制区，不覆盖模型。
- 180个示踪粒子表现混合气进入、压缩、点火反应和废气排出；压缩阶段数量保持不变。颜色、数量、火花持续时间及火焰均为教学示意，不代表分子、配比、真实燃烧速率或CFD结果。
- 观察模式显示运动方向、气门状态与能量变化；辨认模式隐藏名称和转角读数，判断冲程、半圈转动和主要能量特征。压缩：机械能转为内能；做功：内能转为机械能。燃烧的化学能转为内能，吸排气仍需要机械功。
- 已在Node环境解析GLB并检查11段动画、9个转角下的活塞位置，以及冲程边界、答案隐藏、正确/错误作答与切换清除。网页渲染未在本执行环境中进行浏览器截图验收。封面为确认模型的Blender实景渲染。
