# DZ47 空气开关 · 单极内部结构（V53 页面修复版，V52 模型）

> 当前在线案例：`models/dz47-breaker.html`。**1P 单极教学结构**，不是原厂工程 CAD，也不是 2P 双极联动成品。
> 2026-10-24 已将原双极示意初版替换为由 Blender 模型封装的单极 V52 引导教学版，旧版仍可通过 Git 提交历史查看。

## 模型来源与装配边界

- 单极模型来自用户已经验收并手动导出的 `DZ47_Classic_MCB_1P_Clearance_V51.glb`，在后续 V52 编辑中保留断路器有效网格与动画，清理了无关场景数据。
- V52 改进：双金属片及铜色复合层细分为 24 段连续弯曲网格，变形从固定根部逐渐增大，避免整体刚性旋转；U 形连杆附近悬空的销轴/轴肩重新校位；过载引导强化拨杆支点和锁扣的观察。
- 关键部件：手柄、销轴、U 形连杆、储能弹簧、动静触点、热脱扣双金属片、电磁线圈与铁芯、锁扣与灭弧栅片。机械细节为**典型 DZ47/C45 热磁式小型断路器教学近似**。
- 目前没有厂家的完整生产装配图、材料公差及脱扣实验数据；不能把几何位置和教学关键帧视为该产品的真实制造参数或实测保护曲线。
- 普通 MCB 内无玻璃管保险丝，也不提供剩余电流漏电保护功能；本案例不用于电气施工、选型或安全测定。
