# DZ47-63 双极小型断路器 · 资料、装配与验收（V1）

## 定位与依据

- `models/dz47-breaker.html` 是 **2P / C32 微型断路器结构教学模型**，不是实物工程尺寸的 1:1 复刻，也不是电气设备仿真或电流保护设计工具。
- 外观参照课堂提供的 DZ47-63 C32 双极产品照片。无法通过照片确认原厂内部的零件几何和内部极性排列。
- 核心结构参考：[人民电器 DZ47-63 系列说明书](https://www.chinapeople.com/chanpin/diya/3/1/DZ47-63/DZ47-63-SMS.pdf)、[ABB Miniature circuit breakers](https://library.e.abb.com/public/a0e54ab7423d4dd0a609c0f1e0abace2/1SXP403001C0203.pdf)、[微型断路器拆解介绍](https://www.elecfans.com/yuanqijian/kaiguan/202003211187453.html)。
- 断路器具备操作手柄、接线端、动静触点、双金属片、磁脱扣线圈和铁芯、脱扣锁扣和弹簧、灭弧室；**不存在玻璃管保险丝**，此普通 MCB **不提供剩余电流/漏电保护**。
- 各厂家可能采用不同的导电连接和脱扣连杆布置，**本版的具体轴承、导线、灭弧栅片数量及片形、上下铜片走向属于教学近似**。任何精确机械尺寸和触发曲线需原厂拆机或工程资料进一步核对。

## 模型与程序

- 独立 HTML，不调用 CDN，仓库版使用 `../shared/vendor/three-r160.min.js`；分享版将 r160 嵌入同一 HTML，可直接离线打开。
- 前后壳体、两极内部腔体、每极一组端子/触点/热磁保护/灭弧室。完整外观、单极盖板隐藏（作为单极剖视观察）、去壳、分解四个视图。
- 动触点由独立旋转组驱动；双金属片可弯曲；电磁铁芯位移、锁扣角度、两极触点同步响应同一保护状态。
- 正常状态允许手动合闸和分闸；过载状态缓慢弯曲，后释放锁扣；短路时铁芯先动作、触点快速打开、短暂出现教学电弧；通过时间轴可逐帧观察。动画时间**经过教学加速**，不代表具体品牌的秒级脱扣数值。
- 电流红点沿一个教学近似的串联路径移动，且仅在触点闭合时显示；在实际交流电路中，红点运动并不等于载流子的持续单向流动。
- 旋转：左键拖动；平移：右键或 Shift + 左键；滚轮缩放；点击零件看说明。支持 PNG 导出。

## 浏览器回归测试（必做）

1. 刷新完整外观页，确认模型非空白，鼠标往左拖时模型符合仓库统一方向；滚轮缩放与平移无卡顿。
2. 切单极剖视，确认保留一侧外盖，另一侧能看到触点/线圈/灭弧室；切隐藏外壳，应同时看到两极内部部件。
3. 切分解模式，拖动分解距离，检查悬空件、互穿和模型复位。
4. 正常模式点击手动分闸/合闸，确认触点接触/断开与红色电流点显示一致。
5. 过载模式播放到 50%：双金属片应弯曲但触点仍接通；到 100%：两极触点断开，电流点消失。
6. 短路模式播放到 25%：铁芯已响应；60%：触点打开并有短暂电弧；100%：电弧消失。
7. 点击 `电磁线圈`、`双金属片`、`动静触点`，检查零件说明与模型部件相符。
8. 点击保存 PNG，验证视图正常输出；断网打开独立分享 HTML 检查离线资源。

## 下轮需核验

- 目前“单极剖视”为一侧外盖移除，不是连续任意截面的几何切割；如教学确需连续剖切，应实施材质裁切与真实截面封帽。
- 栅片、触点和弹簧的尺寸与不同厂家型号可能不一致。完成实测后再评价尺寸与触点间距。

## V2 · 2026-10-21 几何干涉与储能弹簧修正

针对用户提供的去壳截图发现的机械问题，已进行结构重排。此记录优先于上方 V1 的视觉验收状态：

- **动触点与灭弧室**：改为由右侧固定转轴向左上方开闸。灭弧栅片布置在触点间隙侧后方，与动触点臂的整个旋转包络保持间距，而非穿过栅片。
- **弹簧机构**：拆掉没有任何约束的直立装饰弹簧，改为围绕动触点轴的实际三维扭转弹簧；一端通过立柱与外壳背板固定，另一端借连接销与动触点臂相连；钢轴贯穿线圈。
- **弹簧动作**：用教学意义的扭转弹簧储能、锁扣释放、带阻尼的二阶开闸响应计算触点角度。合闸时储能，热/磁机构分别触发同一锁扣，开闸时弹簧储能持续下降，并驱动两极触点分离。该角度响应是定性物理模型，不等同于原厂弹簧常数与触点断开时间。
- **热保护**：将分离悬浮的阶梯形金属块替换成相邻链接式连续双金属片，热变形沿条带渐进，触发锁扣前不自动断开。
- **联动机构**：将原先遮挡触点及弹簧的横杆移到两极机械后层，改为支撑在轴承中的公共旋转脱扣轴；其转角随脱扣进度变化。
- **外盖位置**：前盖整体前移，保证弹簧及活动零件处于外壳内部，避免穿出外壳。
- **电流路径**：随实际触点接通判据更新状态，不让触点尚未接触时继续出现红色电流粒子。

### 已执行的几何与动作测试

- Chromium + Three.js 实体几何构建使用替代 WebGL 渲染器执行，重建两极全部模型、四种观察模式、三种保护模式与扭簧模型，无未捕获的 JS 异常。
- 对短路开闸全过程取 41 个位置 × 2 极，实物几何包围盒检查共 **82 组**：动触点臂与灭弧室、扭簧线圈与灭弧室均 **0 组 AABB 相交**；确认静/动触点闭合中心 XY 对齐。
- 对正常、过载、短路三个模式采样测试：过载锁扣释放前触点持续闭合，短路磁脱扣后迅速分离；扭簧模拟势能从合闸约 2.969（任意单位）降至接近零。
- **尚未通过**：实际 WebGL / GPU 视觉验收。测试环境 Chromium 因 WebGL 上下文无法创建而不能生成真实三维截图；零件间外观小尺度问题还需在真实浏览器中继续核验。AABB 检查不能代替人工逐零件装配审核。

### 回归重点

1. 首次打开检查正面外壳与手柄未穿模；隐藏外壳近看触点扭簧的两端是否真实连到固定支架与转动销。
2. 播放「短路瞬动」，观察铁芯先动作、锁扣转开、扭簧松开、动触点朝左旋开，禁止任何部分划入灭弧室。
3. 切换「持续过载」，50% 前触点保持闭合；75% 左右才应开始释放锁扣。
4. 进入分解模式后重新恢复，检查面盖、扭簧、公共联动轴及两组触点位置都返回初值。
5. 若原厂拆机照片与当前的支点、弹簧种类、脱扣杠杆布置不同，应优先按实物资料重建，不把教学近似标为1:1拆机复刻。
