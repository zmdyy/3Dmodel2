# 干湿球温度计 · 蒸发吸热与空气湿度（V11）

- 正式入口：`models/wet-dry-bulb-psychrometer.html`
- 分类：热学实验
- 三维技术：内嵌 Three.js r170 / WebGL、PBR 材质、程序化几何、Canvas 纹理与 SVG 矢量读数
- 运行：可单独保存为 HTML，在支持 WebGL 的浏览器中离线打开；无需 CDN、外部图片或在线字体

## 实物结构与复用

按传统双玻璃温度计式干湿球湿度计建立干球、湿球、玻璃感温泡、毛细管、液柱、共用木质背板、两块同尺寸刻度板、顶部金属固定夹、湿球纱布、吸水带与蒸馏水杯。刻度板使用同一尺寸和 SVG 纹理，对称定位，量程 0～45 ℃；显示颜色采用黑色高对比刻度。下部两处金属卡架已去除，以防遮挡读数。

设计借鉴仓库既有温度计案例的毛细管/高精度刻度、测力计的 SVG 读数与放大、细管实验的玻璃容器/水体和屏幕空间导航；并非复制一套测力计模型。

## 课堂交互

- 设定空气温度 10～45 ℃、相对湿度 15～100%、风速 0～5 m/s，观察干湿球液柱的连续变化；
- 湿纱布断水与复位；供水中断时湿球逐步回温，湿度读数不可用；
- 蒸发教学示踪粒子可开关。水蒸气本身不可见，粒子仅用于教学说明；
- 正视、侧视、放大观察、湿球特写、复位与专注模式；左拖旋转，右拖/Shift 左拖平移，滚轮缩放；
- 右侧以 SVG 显示两球温度、温差和相对湿度的估算。

## 计算方法与适用边界

采用饱和水汽压近似式 `e_s(T)=0.61078 exp(17.2694 T/(T+237.3))`（kPa），联立通风湿球近似关系 `e=e_s(T_w)-γ(T_d-T_w)`，按模型选定气压 101.325 kPa 与简化风速相关系数数值反求湿球温度。湿球和干球由同一状态数据源驱动三维液柱、右侧数值及 SVG 读数。

该模型用于说明蒸发吸热与湿度关系：固定气压、忽略辐射误差，低风速修正仅为教学近似，不等同于气象部门的正式湿度查算表或校准仪器。干球温度和相对湿度是实验设定值，不是实际测量采样值。
