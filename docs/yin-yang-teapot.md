# 阴阳壶 · 双腔气压实验

[打开案例](../models/yin-yang-teapot.html) · [真实场景封面](../assets/covers/yin-yang-teapot-scene.jpg)

| 项目 | 实现 |
|---|---|
| 教学目标 | 在同一倾角比较 A 腔出水、B 腔出水、两路出水和封孔停流。观察空气从哪里补入，以及为什么封孔后水会停下。 |
| 结构 | A 气孔从壶盖通向上腔。B 气孔设于壶把下端，通气道抬升至下腔后部的液面上方。两储液腔由隔板分开，两路出液道仅在壶嘴末端汇合。 |
| 物理状态 | 气孔通气时，腔内气压近似等于大气压。气孔封闭、出液道液封时，按等温气体近似更新腔内气压。以液柱压强与腔内外压强差的合量决定流量；同一状态驱动液面、余量、气压、示踪和水柱。计算内部用 Pa、s、rad；液柱换算约为每场景单位 550 Pa，外形与流速为教学尺度。 |
| 引擎与公共资源 | 本地 Three.js r160，配套 OrbitControls，公共 `Navigation3D.configureOrbit` 与材质处理层。保留青瓷釉、半透明液体和水柱的专用材质。 |
| 视角 | 默认整壶，另有双腔剖视和壶嘴特写。手动旋转、平移或缩放接管镜头。自动演示依次对照 A 路、B 路、两路、停流和扶正。 |
| 来源与边界 | 参考[良心壶结构](https://ssac.sic.cas.cn/zlzz/201202/t20120229_619403.html)和[两心壶课堂教具](https://m.fx361.com/news/2017/0610/1903996.html)。采用青瓷外观和上下分腔的教学模型。箭头、液柱尺寸、汇合混色和水花用于定性观察。 |

在双腔剖视下，封 A、开 B 再倾倒，可以沿绿色箭头观察下方气孔补气，并用琥珀色水确认下腔的出水路径。壶嘴特写可观察共用出口的截面。
