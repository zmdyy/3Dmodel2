# 大气压拓展 · 四个器物实验

[打开案例](../models/yin-yang-teapot.html) · [实际运行封面](../assets/covers/yin-yang-teapot-scene.jpg)

首页入口沿用原案例 ID。打开后先显示普通壶，顶部依次是普通壶、阴阳壶、公道杯、汲酒器。首次选中时加载该场景，切走后暂停，切回后继续。

| 案例 | 结构与观察 |
|---|---|
| 普通壶 | 与阴阳壶共用外形，内部是单一储液腔、一条出液道和一个壶盖气孔。可对照开孔出水、封孔停流和开孔恢复。 |
| 阴阳壶 | 隔板分开上下两腔，各有补气路径。两条出液道在壶嘴末端汇合。可对照 A 路、B 路、双路出水与封孔停流。 |
| 公道杯 | 中央柱的陶瓷剖面保留倒 U 形通道。水越过管顶后启动虹吸，进水孔露出后空气进入并断流。 |
| 汲酒器 | 竹节柄侧孔负责补气，底孔进出液。五步演示展示开孔浸入、封孔、提起持液、移到杯上及松孔放液。自动对照另演示开孔提起时回流。 |

## 实现与资料

- 共用本地 Three.js r160、配套 OrbitControls 和公共导航配置。左键旋转，右键或 Shift＋左键平移，滚轮缩放。汲酒器可直接拖器柄升降。外形、剖面、箭头、水柱与读数由各实验状态驱动。
- 两种壶的封孔实验采用壶盖接缝密封、出液道保持液封的教学条件。使用液柱压差和等温气体近似。公道杯和汲酒器的比例、纹饰和流速按教学需要简化。
- 参考[良心壶结构](https://ssac.sic.cas.cn/zlzz/201202/t20120229_619403.html)、[公道杯课堂虹吸演示](https://lecturedemos.ph.utexas.edu/demo/294)及[《临淄区志》汲酒器结构](https://shandong-chorography.org/database/c34/section/8/article/703/)。
