# 纸筒照相机：调焦、拍摄与像高测量

入口：`models/paper-tube-camera.html`，分类为“光学仪器”。

## 结构与操作

按用户提供教材图建立黄、绿双纸筒、凸透镜及手柄、后端半透明薄膜。绿色纸筒同轴滑动，整个调焦行程保持套接；透镜与薄膜有效区域分别独立装配。纸筒长度与口径为教学设定，并非实物测绘。

默认拍摄场景固定盆景，左键拖动相机机身或按住靠近／远离按钮改变物距；左键拖动绿色纸筒改变薄膜距，二者独立。移动相机不自动调焦。空白左拖旋转，右键或 Shift＋左键平移，滚轮缩放；触屏双指平移缩放。纸筒特写、剖开外壳、薄膜正视保留。

拍摄实验使用 40～160 cm 物距、7.50 cm 固定焦距及 8.00 cm 固定物高。远／中／近按钮只改变拍摄距离。结构观察中可使用原有 5～10 cm 焦距与 40～300 cm 物距；超出纸筒行程时给出方向正确的提示。

## 物理与测量

- 近轴薄透镜：`v = fu/(u−f)`，清晰时 `h = Hv/u`。
- 画面缩放按当前薄膜距离与物距计算，离焦半径按圆形孔径的光线采样近似。照片源图由场景中同一盆景沿光轴的正视投影获得，没有用另外的盆景图片替代。
- 盆景高度归一为 8.00 cm；薄膜有效尺寸为 3.60 × 2.70 cm。像高由薄膜坐标比例换算，并标出上下边界。输出保留两位小数，属于模型中的几何长度，不声明实物测量精度。
- 光路图中 `O` 为光心，`F′` 为像方焦点，`B′` 为所选物点的像点。`v` 标注清晰像距；金色薄膜标注实际薄膜距，失焦时二者分开。

| 物距 u / cm | 清晰像距 v / cm | 像高 h / cm |
| --- | --- | --- |
| 160.00 | 7.87 | 0.39 |
| 80.00 | 8.28 | 0.83 |
| 40.00 | 9.23 | 1.85 |

只有画面清晰时才能保存对比卡，最多 6 张。卡片保持同一薄膜比例与厘米标尺，记录当时画面、物距、薄膜距、像高和焦距；后续改变参数不改写已有记录。记录保留在当前浏览器，可删除、清空或导出 PNG 对比图；无法使用浏览器存储时提示导出。

## 显示近似与公共资源

总体场景的长距离区段压缩显示，并在画面中明确标识；实际物距以读数为准。纸筒局部装配与定量成像不使用压缩后的场景距离。盆景用同一目标平面近似，不模拟其不同景深；忽略像差、衍射，亮度作投屏补偿。

复用 `shared/vendor/three-r160.min.js`、`shared/navigation-style.js` 和 `shared/material-finish.js`。纸筒与植物已有程序纹理和哑光材质，设置 `noMaterialFinish` 保持已验收颜色与源图一致；光学玻璃、光线和薄膜不套用旧化。字体以子集内嵌并保留 SIL OFL 许可。没有 CDN 依赖；仓库页面通过 GitHub Pages／静态 HTTP 使用。

## 封面与验证

首页封面 `assets/covers/paper-tube-camera-scene.jpg` 是本案例默认拍摄场景的真实浏览器 WebGL 画布截图，960×540；只隐藏操作界面、调整画布尺寸，不另建封面模型。

实际 Chromium 验证：初始 WebGL、机身与绿色纸筒独立拖动、改变物距后不自动调焦、未清晰禁拍、远／中／近三次成像及长度、记录刷新保留、PNG 导出、视图切换、手机布局无横向溢出。入库另检查公共资源加载、首页检索与 iframe 打开／关闭。

参考用户教材“自制的模型照相机”；[威斯康星大学照相机演示](https://www.physics.wisc.edu/ingersollmuseum/exhibits/opticscolor/camera/)与 [Photoworks 套接式暗箱制作](https://photoworks.org.uk/learn/how-to/make-a-camera-obscura/)用于结构原理核对。
