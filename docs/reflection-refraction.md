# 光的反射与折射：透明块与完整光路

`models/reflection-refraction.html` 保持独立、离线可用的 SVG 三维投影实验。

## 透明材料

- 半圆块增加厚度侧面、倒角、基底阴影与淡青渐变；盘面刻度和实验光线保持可辨认。
- 空间折射的实心半球增加体积包络、曲面边缘明暗及平面高光；后方支架透过材料时被透明表面染色、淡化。空间反射的空心罩保持原有结构。
- 色调和表面明暗是体积辨识的辅助表达，不代表实际有色 PMMA 的吸收系数；背景透视不是光学成像追迹。

## 形状与光学

“02 透明块折射”和“04 空间拓展／空间折射”可选半圆／半球或长方体。长方体完整追踪空气→材料→空气；使用真实包围盒求交及两次斯涅尔折射，并按两界面的菲涅耳透射率累计主透射光功率。比例保证当前 0–85°、PMMA/PC 参数中主光线穿过相对的平行表面，出射方向与原入射方向平行，非零斜入射时具有侧向偏移。

B 光源放在实际出射点外，朝向出射点。反向发光时，内部路径和最终外部方向均沿正向主光路返回；两个界面的法线、角弧和标注随发光方向更新。读数、记录对应当前发光端首次遇到的入射界面①；界面②的两侧角度另在画面标注。未展开弱多次反射。

全反射探究继续使用半圆块的径向入口，不在该模式显示形状切换。原有空间反射、翻折、读角拖动、记录及 SVG/CSV 导出保留。

首页封面 `assets/covers/reflection-refraction-scene.jpg` 为默认半圆折射场景的浏览器 SVG 实际截图，隐藏界面后保存为 960×540 JPEG。

## 检查

`node scripts/tests/optics-refraction.cjs` 需要 Playwright 和 Chromium；可用 `OPTICS_BROWSER` 指定可执行文件。检查 200 组材料、角度、入射侧与空间方位组合，验证两次斯涅尔定律、平行出射、交点落在实体边界、反向内部路径及最终方向，同时检查界面法线、全反射和浏览器错误。
