# 地磅 · 载重与电流

按用户提供的单文件 HTML 原样导入。采用 Anatomy 的三维几何投影 SVG 渲染，带内嵌排序 Worker、字体和许可；不需要 Three.js 或外部 CDN。保留原作品声明及 MIT/OFL 许可。

支持 4–20 t 载重、两种接线、开关、自动演示、敞开弹簧、电流效果、原理图、明暗主题和局部视角。左拖旋转、右拖或 Shift＋左拖平移，滚轮缩放。

电源 3 V，保护电阻 5 Ω，变阻器 15 Ω，四弹簧等效劲度系数 2.0×10⁶ N/m。此模型说明题图中的弹簧—电阻式传感原理；现代工程地磅通常使用应变式传感器。显示器按 3 接 2 标定，改接 1 后显示质量会随实际质量反向变化。

原文件：地磅_载重与电流_3D演示 (3).html。首页封面来自实际运行场景。
