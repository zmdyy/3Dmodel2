# 高架桥桥墩 · 结构与桥下空间比较

## 教学目标

在统一桥面、道路和观察条件下，比较常见桥墩的支承布置、墩底占地、桥下连续净宽、驾驶视线遮挡，以及桥下道路、停车和步行空间的组织差异。

## 类型范围与分类边界

本案例展示：
- 柱式布置：单柱T形、双柱式、多柱排架；
- 框架/跨越式：门式墩；
- 分叉造型：Y形墩；
- 墩身造型：花瓶形墩；
- 偏心悬臂构造：倒L形墩；
- 薄壁截面：板式墩；
- 山区高墩拓展：空心薄壁高墩。

这些名称并非同一分类层级。单柱/双柱/多柱描述支承布置；Y形/花瓶形/倒L形描述几何或构造形态；板式/空心薄壁描述墩身截面特征。实际工程可以组合使用。

## 统一模型假设

- 城市比较场景：桥面宽18m，桥下道路宽18m，桥下净空约7.25m，墩位沿桥向间距14m；三排墩用于展示连续空间效果。
- 城市桥墩各型尺寸为教学建模参数，非真实工程尺寸，也不用于结构验算。
- “单排墩底占地”按本模型每一排墩柱/墩身投影面积估算。
- “最大连续净宽”按道路横断面上模型墩底投影区间计算；不包含防撞护栏、检修通道、地下管线、车辆扫掠轨迹等工程约束。
- “视线射线受阻”使用驾驶员眼高1.55m、17条水平射线进行几何求交。它不是道路视距规范验算，也不代替真实驾驶视距分析。
- 维护缓冲区显示1.5m示意范围，参考天津市城市桥梁桥下空间管理文件中的地方性要求，不代表全国统一规定。
- 倒L形墩场景中灰色柱为既有桥支承示意，避免把偏心扩建支承误解为独立对称桥跨。
- 空心薄壁高墩切换到山区峡谷场景，不与城市低墩的占地/净宽数值横向排名。
