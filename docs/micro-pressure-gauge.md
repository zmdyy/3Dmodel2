# 微小压强计

## 文件与入口

- 页面：`models/micro-pressure-gauge.html`；程序：`shared/micro-pressure-gauge.js`；物理计算：`shared/micro-pressure-physics.js`。
- 使用仓库本地 Three.js r165 与统一 Navigation3D 配置。普通视角左键旋转、右键或 Shift+左键平移、滚轮缩放。
- 剖面局部使用正交相机，法线与剖切面一致；关闭旋转，允许缩放和平移。回到整体视角恢复透视相机和旋转。未变形参考仅一条直径虚线。
- 下方两个金属固定环已删除。上方固定环保留。玻璃采用透明中心、较明显边缘和双层管口壁厚。

## 三个实验

1. 橡皮膜：外液静压与管内气压、膜恢复力共同平衡；膜参数为教学示意。先在空气中检查气密性并调零。
2. 开口玻璃管：下端开口，上端经密封软管连接 U形管右侧，左侧通大气。液体进入管内并压缩空气。记录管口深度 d、外液面到管内液面的距离 H、U形管液面差 Δh。静止时 ρ待测 gH = ρ测压 gΔh；同时满足等温气体压缩与 U形管移液量。d = H + 管内进液高度，不能直接用 d 替代 H。
3. 气流：透明收缩管喉部侧向取压，出口通大气；喉部与出口面积比 1∶4。理想低速稳态模型中，喉部表压 = −½ρ空气(v喉² − v出口²)。右侧液面上升，Δh 显示差值绝对值，压强显示带符号。

待测液体：清水 1000、浓盐水 1200、轻质油 800 kg/m³。开口玻璃管另有 3000 kg/m³ 的高密度教学液体，非指定化学品。测压液体可选 800、1000、1260 kg/m³。忽略毛细作用、空气重量、液体混合、温度变化与容器液面小幅变化。

剖面显示 ×1、×3、×5、×10，仅放大显示；内凹显示限制在 11 mm，防止穿过腔体后壁。实际深度、压强、膜形变量与记录不受影响。初始预压气体可能使膜向外凸，入液并调零后按真实压差变化。

操作区只保留参数、读数和记录。原理与异常说明收进问号及探究提示。三个实验分别保留当前页面的记录；支持 Δh—d / Δh—H 图像、理论趋势、删除、清空和 CSV 导出。
