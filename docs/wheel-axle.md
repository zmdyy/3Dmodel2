# 生活中的轮轴 · 四种实物观察

## 教学目标

比较轮与轴在相同转角下通过的距离，观察手施力和轴处等效切向力。四个案例的 3D 装置、沿轴观察 SVG 原理图、滑块和读数共用进度。水井转轴为水平轴，原理图从摇柄端沿轴看。

| 案例 | 运动与观察点 |
|---|---|
| 螺丝刀 | 蓝黄一字螺丝刀驱动螺丝旋入，螺纹特写使用实际螺旋网格，支持纵向剖切 |
| 扳手 | 开口梅花两用扳手以梅花端驱动螺母 |
| 水龙头 | 手轮带动阀杆与阀垫升降。阀垫闭合时封住进水侧，开启后可看示踪点经过阀座、阀腔和出水嘴，落入嵌入台面的瓷盆 |
| 水井辘轳 | 摇柄、轴和卷筒同转，绳从卷筒切点垂下并连接水桶。井壁留观察口，默认斜视 |

## 复用与近似

- 单一 Three.js r160 实例。本地 `shared/vendor/three-r160.min.js` → `shared/lab-kit/navigation.js` → 案例脚本。复用 `camera-navigation@1.0.0` 的取景与手动接管，无新增公共模块。
- 模型坐标 m、角度 rad、时间 s、力 N。界面用 mm 标示半径，理想切向力按 `f = F R/r`。扳手为等效半径，水井按单层卷绕，水流为定性示踪。
- 左拖旋转，右拖或 Shift+左拖平移，滚轮和双指缩放。拖动蓝点直接操作器材。案例标签取局部视角，全景由用户主动开启。
- 下载仓库后保持 `models/` 和 `shared/` 相对目录结构，直接打开 `models/wheel-axle.html`。运行时仅加载两个本地脚本。

## 封面与验收

- 封面取自 Chromium/WebGL 的水井辘轳场景。截图调整视口并隐藏操作界面，尺寸 960×540。
- 106 组联动样本检查 3D 状态、SVG、阀垫行程、连贯水路和切换状态，另检查台面开孔、瓷盆对位与卷绳颜色一致。
- Chromium/WebGL2 下用本地文件实际打开，验证四个标签页的滑块与 SVG、螺纹特写和水路剖切。仓库既有浏览器复用测试及三种 SVG 样式测试通过。复用登记检查仍报告既有 `models/thermometers-thermal-expansion.html` 来源哈希不一致，影响 `lab-kit.cjs` 的登记验证步骤。
