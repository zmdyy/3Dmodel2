# 深中通道 E15 · 沉管浮运安装

- 文件：`models/shenzhong-e15.html`，沿用确认的 V26 独立离线版，原生 WebGL / Canvas，无外部资源请求，无需套用 Three.js 专属材质层。
- 十阶段：浮运、系泊、沉放、着床、机械拉合、水力压接、内部施工、脱缆、锁固、保护回填。自动镜头按工序定位；鼠标接管后停止跟随，可平滑恢复。
- 局部施工复用原 V13 封门拆除 / OMEGA 教学模型，通过明确标记的教学尺度映射展示；没有新造施工详图。原独立模块收在“更多操作与参数 → 拓展模块”。
- 海水保留半透明表面、反光、船体倒影与蓝绿色水下雾；低配置档减少反射开销。主视图采用左拖旋转、右拖或 Shift＋左拖屏幕平移、滚轮缩放；平移按当前相机基向量计算。

## 资料和边界

原文件保留了中交一航局、沉管运输安装一体船及供料锁固系统研究、ITA-AITES 与 T/CIN 082—2025 等工程资料名称与说明。190.4×75 m 船型、165×46×10.6 m 管节采用原文件列明的公开尺寸。基床 -32 m、实际机位、吊索倍率、局部封门数量及后装顺序等为教学推定，不代表 E15 原厂详图或实测记录。海水与能见度为视觉近似，压差曲线为归一化示教。

## 验证

V26 已完成十阶段实际画面检查、连续播放到 100%、前后跳转、手动接管及恢复，以及展开图纸后的自适应取景；原始总体网格保持不变。仓库接入另检查首页卡片加载、模型独立打开、平移方向和封面资源。
