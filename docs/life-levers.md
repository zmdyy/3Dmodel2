# 生活中的杠杆 · 七种实物观察

## 教学目标与来源

依据用户上传的 `life_levers_3d (6).html` 入库，保留已确认的七种器材结构、运动与内嵌实物照片。观察支点、转轴、动力与阻力作用处，比较长短臂的运动；不据动画计算真实力值。照片来源及各型号说明随案例保留，来源链接需联网，照片本身已嵌入。

## 复用与范围

| 项目 | 本例实现 |
|---|---|
| 引擎 | 上传文件内嵌引擎与公共 Three.js r160 内容一致，改用 `shared/vendor/three-r160.min.js`，单实例 |
| 材质 | r160 → `shared/material-finish.js` → `shared/lab-kit/navigation.js` → 场景；哑光金属、微表面纹理，保留原玻璃和已有贴图；中性摄影棚地面退出旧化，避免大面积纹理干扰 |
| 资源 | `camera-navigation@1.0.0`，球面相机、全景适配及手动接管；未新增公共资源 |
| 连接关系 | 开瓶器接触瓶盖；镊子固定端与弹性夹臂；箱体与拉杆绕轮轴；车架与车斗绕轮轴；锤头在木板上滚动；剪刀共轴；指甲钳压柄经销轴作用于弹性刀身 |
| 单位 | 继承原例各物品归一化展示单位，不是实物米制尺寸；角度 rad、动画时间 s；不连接公共米制器材，不计算力 N |
| 状态 | 七种器材分别通过同一进度 q∈[0,1] 驱动模型、作用点、轨迹与标签；进度、播放和蓝色操作点同步 |
| 简化 | 瓶盖弯曲、镊子和刀身弹性、拔钉滚动为定性运动近似；独轮车货物随斗固定；未作应力与散料模拟 |
| 视角 | 整体、正视、俯视、背面、支点近看；使用原模型包围盒与实际支点取景，无自动追踪 |
| 导航 | 左拖旋转，右拖/Shift+左拖屏幕平移，滚轮缩放，双指平移缩放；普通左拖蓝点操作器材，Shift 优先平移 |
| 特写与字体 | 本例使用同一主场景的支点近看，无读数窗；保留 DOM/SVG 标签与系统中文字体 |
| 离线范围 | 仓库下载后保持 models/shared 目录结构，可用 file:// 打开；仓库版不是单文件，原上传单文件保持不变 |

## 封面与验收

封面为默认开瓶器场景真实 Chromium/WebGL 截图，960×540 JPEG。仅隐藏 UI、调整画布和重新取景，未重建模型或生成图片。脚本：`scripts/capture-life-levers-cover.cjs`。

2026-11-01 验收：

- Chromium/SwiftShader 实际 WebGL2 渲染七种器材的 q=0/0.5/1 共21组状态，包围盒有限，指甲钳刀口未出现负间距；七组实物照片成功解码。
- 检查公共材质层实际应用；左拖旋转、右拖与 Shift 左拖平移、滚轮缩放通过。Shift 在蓝点上拖动只平移，普通蓝点拖动改变实验进度。
- 390px 窄屏无横向溢出；本地 file:// 打开时阻断全部 HTTP(S) 请求仍能运行；首页 deep link 与 iframe 案例加载通过。
- `node scripts/tests/reuse-browser.cjs` 与 `node scripts/tests/instrument-patterns.cjs` 使用 `LAB_KIT_CHROMIUM` 指定 Chromium 后通过。
- `python scripts/reuse-context.py --validate` 及依赖它的 `lab-kit.cjs` 被主分支既有的 `models/thermometers-thermal-expansion.html` 来源哈希漂移阻断。本次未修改该温度计文件或注册表；未将该全局检查标为通过。
- 未重新验证七种器材的实物尺寸、制造公差或真实受力；本次是已确认模型的入库适配。
