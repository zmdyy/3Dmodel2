# 生活中的杠杆 · 九种实物观察

## 教学目标与来源

依据用户上传的 `life_levers_3d (6).html` 入库，保留已确认的七种器材结构、运动与内嵌实物照片。观察支点、转轴、动力与阻力作用处，比较长短臂的运动；不据动画计算真实力值。照片来源及各型号说明随案例保留，来源链接需联网，照片本身已嵌入。

## 封面与验收

封面为默认开瓶器场景真实 Chromium/WebGL 截图，960×540 JPEG。仅隐藏 UI、调整画布和重新取景，未重建模型或生成图片。脚本：`scripts/capture-life-levers-cover.cjs`。

2026-11-01 验收：

- Chromium/SwiftShader 实际 WebGL2 渲染七种器材的 q=0/0.5/1 共21组状态，包围盒有限，指甲钳刀口未出现负间距；七组实物照片成功解码。
- 检查公共材质层实际应用；左拖旋转、右拖与 Shift 左拖平移、滚轮缩放通过。Shift 在蓝点上拖动只平移，普通蓝点拖动改变实验进度。
- 390px 窄屏无横向溢出；本地 file:// 打开时阻断全部 HTTP(S) 请求仍能运行；首页 deep link 与 iframe 案例加载通过。
- `node scripts/tests/reuse-browser.cjs` 与 `node scripts/tests/instrument-patterns.cjs` 使用 `LAB_KIT_CHROMIUM` 指定 Chromium 后通过。
- `python scripts/reuse-context.py --validate` 及依赖它的 `lab-kit.cjs` 被主分支既有的 `models/thermometers-thermal-expansion.html` 来源哈希漂移阻断。本次未修改该温度计文件或注册表；未将该全局检查标为通过。
- 未重新验证七种器材的实物尺寸、制造公差或真实受力；本次是已确认模型的入库适配。

## 新增两种装置

- 钓鱼竿：双手抬竿工况。后手握点为等效支点，前手在中间施力，竿梢承受鱼线的等效向下拉力。锥形竿体及导环随同一进度更新，鱼线末段保持绷直。弯曲为教学近似。
- 双翼红酒开瓶器：外形依据用户提供的照片。先对准瓶塞，尖端接触软木塞后，顶柄从上方看顺时针旋转，每圈下行一个螺距，齿条带动双翼抬起。蓝色操作点在旋入阶段位于顶柄，旋到底后移到翼端。随后压翼，中轴齿条上行，软木塞随之离开瓶口。瓶口套和双铰轴固定。双翼对称，齿条位移与翼根节圆半径和转角差关联。尺寸、齿形和力值均为教学简化。
- 复用原页面的相机、进度、拖动、轨迹与支点标签。沿用归一化展示尺寸、弧度和秒。新增场景依赖原有本地 Three.js r160、材质和相机模块。

2026-11-08 增补检查：使用仓库 Three.js r160 在 Node 环境执行九种装置的五个进度状态（共45组），核对有限包围盒和标注。另检查鱼线连接与末段长度、压翼方向、软木塞插入阶段静止及拔塞末端越过瓶口，以及九项导航、进度与照片区切换。界面逻辑检查使用模拟渲染器；本环境 Chromium 下载失败，新增场景的真实 WebGL 画面、触屏和 file:// 冷启动待浏览器验收。首页继续使用未改动的默认开瓶器场景实拍封面。

旋入修正验收：在 Node 环境用仓库 Three.js r160 核对尖端首次接触、接触前不转动、旋入螺距、瓶塞静止及尖端未穿出底面。对比拔塞阶段的中轴、软木塞和双翼姿态，结果与上一版一致。以 Three.js 射线拾取检查两段蓝点拖动和轨迹切换。双翼随螺旋深入而抬起的工作顺序参考 [OXO 双翼开瓶器说明](https://www.oxo.com/steel-winged-corkscrew-641.html)。

## 齿条啮合与观察区修正

- 双翼开瓶器沿用环形齿条结构。翼根改为铜色渐开线扇形齿，银蓝色中轴使用梯形截面的环形齿条。两者共用齿距，齿条节线距中轴等于铰轴横距减去翼齿节圆半径。旋到底时，翼齿对正齿条齿槽。环齿延伸到完整行程，导向套、瓶口套及背部支架留出运动间隙。齿形和材质配色是教学处理。结构依据 [EP2874938A1 图 1 及传统环形齿条说明](https://patents.google.com/patent/EP2874938A1/en)。
- 九项器械切换移至页眉，宽屏与标题同排，窄屏可横向滑动。三种标注文字置于画布外的观察工具栏，模型上保留点位和细引线。观察提示移入侧栏。
- 使用实际 Three.js r160 几何在 601 个进度位置扫描左右翼齿与中轴最大径向截面，检查齿形交叠、齿根间隙及节线覆盖。另回归旋入、拔塞和蓝点操作，并检查公共页面结构中标签与画布分离。
