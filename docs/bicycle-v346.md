## 拖拽操作验收要点

1. 以整车视角检查左键水平拖拽，靠观察者的一侧随鼠标方向旋转。
2. 右键平移和 Shift+左键平移一致，且不改变机构参数。
3. 滚轮放大/缩小不会改变模型装配关系；双击回到整车视角。
4. 从演示页切到操作/视角/显示时，旧演示停止写入运动参数。
5. 按 0%、50%、100% 刹车强度检查原始银色刹车手柄的铰接；另外检查脚踏、链条、轮圈与水滴。
