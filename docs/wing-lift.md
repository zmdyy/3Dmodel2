# 机翼升力 · 流速与压强

| 模块 | 操作与观察 |
|---|---|
| 文丘里管 | 调节风速，比较管道宽处与窄处的流速，以及连接两处的 U 形压强计液面。液面差按 `Δp = ρ液 g Δh` 计算。 |
| 鼓风机与机翼 | 调节来流，切换正置和倒置机翼，观察压力分布、受力和导杆上的升降。鼓风机喷流为教学示踪，翼面压力采用理想翼型模型，导杆限位与滑动阻尼按教学参数处理。 |

单文件沿用原课件内嵌的 Three.js r128 与 OrbitControls。左键旋转，右键或 Shift＋左键平移，滚轮缩放。拖曳、滚轮或触摸可以接管预设镜头过渡。控制量使用 m/s，压强读数使用 Pa。
