# 热气球与飞艇 · 三维浮力实验室

[打开案例](../models/hot-air-balloon-airship.html)

面向初中浮力教学。两种飞行器都从地面开始，学生可对照接地和离地时的受力，观察热气球加热与拉绳排热、飞艇推进与尾舵操纵。深圳福田 CBD 以程序化三维建筑提供方位和运动参照。

- **热气球**。加热使囊内空气密度降低，球囊充盈后，短时内可将排开空气的体积近似看作不变。拉绳打开顶部伞阀，热空气排出，模型显示随后的下降过程。
- **氦气飞艇**。氦气提供主要的静浮升能力，副气囊帮助维持囊压和调整配平。方向舵改变偏航，升降舵改变俯仰，两者的效果与相对空速有关。第 5 阶段依次展示升降舵上偏与下偏、方向舵左右偏转和飞行方向变化。
- **竖直受力**。浮力按排开空气的重力计算，力以 N 表示。接地时显示向上的支持力，离地后支持力为零。浮力与重力箭头同尺，小支持力箭头为课堂可读性另行加长并标注。受力图聚焦起飞教学所需的竖直力，飞行过程使用简化动力学。
- **实现与验收**。案例内嵌 Three.js r160 和仓库 `camera-navigation@1.0.0`，可离线打开。左键旋转、右键平移、滚轮缩放。飞艇的受力图使用独立区域，桌面置于画布旁，窄屏置于画布下方。可从飞艇整机视图切到第 5 阶段，检查升降舵两个偏转方向、轨迹和受力图均可见。可切回热气球并从起飞坪开始验证支持力随离地消失。
