# 电子秤 · 单点式称重传感器

入口：`models/electronic-scale-single-point.html`。首页封面：`assets/covers/electronic-scale-single-point-scene.jpg`。

## 教学目标与结构

针对只学过欧姆定律的初中生，从完整装置依次观察：横梁受力与微小形变 → 金属栅丝拉伸/压缩 → 两条支路分压 → A、B 两点电压差 → 标定换算质量。

默认打开完整装置，全景显示应变片接线、四个电桥节点、四芯出口与电路板。保留加载、移去砝码、去皮/取消去皮、分层拆解、传感器特写、应变片结构和分步演示。空载砝码隐藏；去皮仅改变显示零点，不改变原始受力、电阻和电压信号。

## 接线与物理状态

| 应变片 | 节点 | 加载趋势 |
|---|---|---|
| R1 左上 | 供电＋、A | 受拉，电阻增大 |
| R2 右上 | 供电＋、B | 受压，电阻减小 |
| R3 左下 | A、供电－ | 受压，电阻减小 |
| R4 右下 | B、供电－ | 受拉，电阻增大 |

梁上节点上下供电、左右检测；绝缘底膜隔开金属梁与导体，边缘绝缘引线汇入四位接口，红/黑/蓝/绿四芯线连接采集板。颜色是本案例约定。真实传感器常将电桥封装，裸露走线、片位和形变为教学展开，不代表某一产品制造布局。

计算：`F = (m_g / 1000) × 9.8`；满量程 1000 g，供电 5 V，基准电阻 350 Ω，灵敏系数示例 2，满量程应变示例 250 με。`ΔR = 350 × 2 × ε`；`U_A = 5 R3 / (R1 + R3)`，`U_B = 5 R4 / (R2 + R4)`；输出 `U_B − U_A`，满量程为 2.5 mV。0–1200 g 可操作，超过 1000 g 显示 Err，应变和电压演示在满量程截停。
