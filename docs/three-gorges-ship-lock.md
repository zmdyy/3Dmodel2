# 三峡船闸 · 三室连通器 V13

入口：[单文件离线案例](../models/three-gorges-ship-lock.html)。三个完整闸室中，相邻有限水体通过底孔、分支廊道与输水阀相连；输水时人字门保持关闭。高侧水面下降、低侧上升，最终齐平后才开门通航。

| 项目 | 实现与范围 |
| --- | --- |
| 教学目标 | 观察水路是否相通、两侧水位共同变化、阀门与通航闸门的分工 |
| 引擎与单位 | 保持用户指定 Three.js r186，官方同版 OrbitControls；单一引擎，m/s/rad，Y向上，水位标高为世界Y+96m |
| 复用 | 内嵌 shared/navigation-style.js 的 configureOrbit；参考 camera-navigation@1.0.0 的手动接管约定，保持原连续导演实现；不混入r160 |
| 连接 | 底孔→支廊道→主廊道反弧阀→邻室底孔；固定缸筒与伸缩杆，吊杆连接阀叶吊点和导向机构 |
| 物理状态 | 等面积280×34m；高低两侧按同一转移体积V更新：h高=h高初−V/A，h低=h低初+V/A；模型、标签和水位读数同源 |
| 范围与简化 | 三室连续片段，非实际五级船闸完整调度；统一96m标高基准、相等面积、夸张示踪、时间压缩、通透闸底与剖墙用于教学；不能用于工程计算 |
| 新增结构 | 三完整闸室、反弧阀面板/支臂/轴承/密封/吊杆、地下廊道、进出水孔；中室底板隐藏，以轮廓及四区标识底部 |
| 镜头 | 全程65.6s，船舶进入、关门、开阀、两室水位、关阀、齐平、开门、出闸；点击自动演示自动启用导演，无独立导演选项 |
| 导航 | 左拖旋转，右拖或Shift+左拖屏幕平移，滚轮缩放，双指平移缩放；首次输入即接管并取消镜头过渡；再次启动自动演示明确恢复 |
| 局部放大 | 不增加浮窗，以主视角聚焦阀门/闸门/连通器，避免遮挡 |
| 字体与外观 | 内嵌中文WOFF，延续原水体透明材质、光照与混凝土/金属配色；案例独立离线运行 |
| 封面 | 当前HTML真实Chromium/SwiftShader WebGL截图，960×540JPEG；仅隐藏面板并改变构图，未重建模型 |

依据和工程参考保留在案例底部。此前用户迭代已确认三室、水位联动、通透底板、精细阀门、自动导演与隐藏多余选项；仓库上传后的首次接管补丁尚待用户课堂体验反馈。

复现封面：`node scripts/capture-ship-lock-cover.cjs`。专项检查：`node scripts/check-ship-lock.cjs`（通过 `CHROMIUM_PATH` 指定浏览器）。
