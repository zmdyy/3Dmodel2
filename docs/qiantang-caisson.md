## 工序脚本

| 阶段 | 进度起点 | 变化、镜头与观察重点 |
| --- | ---: | --- |
| 1. 勘测与导架 | 0 | 木桩墩位、江面、导架与基岩剖切 |
| 2. 射水打桩 | 10 | 当前施工桩位变化，高压射水和打桩锤；其余桩逐渐就位 |
| 3. 沉箱浮运 | 21 | 沉箱与浮具同步移入墩位 |
| 4. 系泊与潮汐定位 | 30 | 锚缆连接、潮位变化 |
| 5. 受控下放沉箱 | 39 | 沉箱下口平移归位后连续下降至桩头 |
| 6. 供气排水 | 49 | 供气升压，作业室内水面降低 |
| 7. 挖泥与沉降 | 59 | 挖泥、土体上表面下降；沉箱略下沉，桩头露出约 0.5m 的教学几何关系 |
| 8. 墩身同步接长 | 72 | 墩身接长，出泥通道与气闸保持连接 |
| 9. 封底与传力 | 80 | 混凝土封底出现，沉箱转为永久基础；传力箭头 |
| 10. 钢梁浮运 | 88 | 跨间全景；钢桁梁与浮具入位、潮位升高 |
| 11. 潮落落架 | 95 | 浮具随潮下落，梁端就位形成双层通行结构示意 |

**所有阶段共享 0–100 进度源。**拖动进度条、直接选工序、播放与重播均调用同一个 `updateState`，减少不同模式的姿态冲突。镜头可自动切换打桩、基础剖切、桥梁全景；拖动/平移/滚轮接管，手动恢复自动跟随。

## 结构与物理检查

1. 沉箱顶板分块留两处真实开孔；气闸竖井和出泥竖井从作业室内向上贯通，不能与一整块顶板相撞。
2. 挖泥阶段沉箱底口从桩头高度下降约 0.5 m，封底时桩头仍在作业室内；木桩不会贯穿顶板。桩长 30 m，实例化降低绘制开销。
3. 开启剖切时，沉箱钢壳、封底混凝土、墩身和土体使用实际裁切平面，不以透明整壳假装剖切；关闭剖切恢复实体表面。
4. 浮运钢梁最终标高与两端墩顶支座基本一致；钢桁梁及双层桥面为教学结构化简，尚未对铆钉、横联及节点板做实物复刻。
5. 降低供气时水面回升属于压气失衡模拟；不是通过放气控制沉箱沉降。施工播放在手动供气不足时防止继续自动挖泥。
6. 潮汐变化与浮具共同运动，不使用固定不动的装船/落架画面。
7. 低配置模式调低像素比并关闭阴影；常规与低配置均使用本地 Three.js。
