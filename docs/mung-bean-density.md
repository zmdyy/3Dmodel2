# 绿豆密度 · 等体积替代

- 入口：`models/mung-bean-density.html`；分类：力学实验。
- 题目条件：①瓶中水至瓶口，称量 m₁；②倒出部分水，称量 m₂；③称量碗及全部绿豆 m₃；④缓慢加豆至原水面，称量碗及剩余绿豆 m₄。
- 示例 m₁=518.0 g，m₂=468.0 g，m₃=210.0 g，m₄=150.0 g，ρ水=1.00 g/cm³；示例密度1.20 g/cm³。所有数值均非原题给定。
- 质量 m豆=m₃−m₄；体积 V豆=(m₁−m₂)/ρ水；密度 ρ豆=(m₃−m₄)ρ水/(m₁−m₂)。忽略吸水、气泡、附着水和溢出损失。
- 液面按瓶截面积积分与排开体积求解，两个终态均回到瓶口。绿豆适度放大，用总体积计算液面，不按渲染粒子数计量。
- 器材由程序几何建立，生成参考图仅用于外观，不作为实物测绘依据。倒水阶段为直立液位下降示意，未模拟倾倒流体；加豆采用示意轨迹，不作刚体碰撞求解。
- 总览以四张步骤卡和质量、体积、密度三张公式卡集中展示；点击任一步骤回到对应3D状态。
- 首页封面取实际默认WebGL场景，隐藏操作面板，无生成图片替代。
- 验收：四步终态读数、首尾液面、加豆中间态、总览跳转、公式显隐、首页检索打开与退出、页面错误检查、静态资源路径检查。
