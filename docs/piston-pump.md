# 手压抽水机 · 引水、密封与单向阀

入口：`models/piston-pump.html`。精细网格：`assets/models/piston-pump-v2.glb`。

## 自由探究界面

沿用滑轮实验室的暖白、青蓝、低反光器材风格。左侧主要空间展示模型，右侧只保留两个核心问题：

- 为什么加水后才能顺利抽水？
- 反复按压，水怎样被送到出口？

选择问题只改变观察提示，不复位装置、暂停动画或移动镜头。原理解释和资料使用可关闭的对话框，不挤占操作区。两个装置模式分别保留状态。按压一次为完整往复周期；逐步适用于观察局部行程。加入引水暂停把手，约8秒的倒水示意后需主动继续操作。切换速度不会改变模拟结果。

## 模型边界

- 跟踪活塞上下腔、进水管、引水、渗流和出口排水的收支。渗水不是凭空消失，而是从上腔转入下腔。
- 空气可压缩性和阀门压差条件构成低速集总示意；干燥密封下快速漏气使压差难以保持，润湿后泄漏减少。
- 流量、渗漏系数和润湿时间未实测标定。定性压强以大气压作参考，不显示精确读数；不声称固定按压次数必然出水。
- 不包含每次飞溅产生新气泡的假设，不模拟气蚀、湍流、水锤或皮碗材料的定量吸水变形。
- 水流和空气符号可独立关闭；只代表流向，大小不代表真实气泡尺寸。液体正常充满下腔时不会人为画出真空空腔。
