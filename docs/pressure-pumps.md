# 大气压与按压泵

页面：`models/pressure-pumps.html`，目录分类“力学实验”。来自已确认的 V4 双案例，保留结构、剖切和状态计算，仓库版引用本地公共 Three.js r160、材质与导航脚本。使用静态 HTTP 服务或 GitHub Pages；公共资源完整时也可直接打开仓库内页面。

## 对象与依据

- 洗手液泵按 [US4991746A](https://patents.google.com/patent/US4991746A/en) 图1—3及详细说明重建：底部进液球阀、球笼、两段泵杆、出液锥面、双唇活塞、回位弹簧与侧孔补气路径。进液球阀不剖切。不是某品牌产品的逆向制造图，未给尺寸按图估计。
- 气囊取水器的外形、绿色阀座、白色薄片参考用户提供的实物及拆解照片。用户确认气囊只通过空气、止水拨钮打开桶内到外界的通路。未见的按钮阀芯、隐藏孔道、孔组分工及密封细节为功能示意，不宣称完整复制照片产品。
- [US5197866A](https://www.freepatentsonline.com/5197866.html) 仅用于核对气压式取水器的结构类型；其专属阀门与回弹通路不是本产品内部结构的证据。相关来源和照片保留在页面的结构说明中。

## 物理与装配

洗手液泵压下时先打开出液锥面，再推动活塞压液；回弹时先密合锥面，再由弹簧抬升活塞，经进液球阀补液。瓶内补气与泵腔输液是两条通路。

气囊压缩时，经单向阀向桶内送入空气；松手回弹时补入外界空气。桶口密封，水由独立长管送至侧向出口，水不通过气囊。开启拨钮让桶内空气排向外界，压强差下降，不能继续克服水柱高度时停止供水。阀片的弯曲幅度放大用于观察。

气囊初始容积约150 mL、行程约90 mL、桶内初始空气约3 L，大气压101.325 kPa，为教学参数而非实物标定。桶内气体按等温理想气体处理，流量由桶内表压减去水柱压强后按简化阻力关系求得；未求解惯性、材料应力和完整两相流。

## 操作与运行

顶部切换两个案例，首次切换才创建补充 iframe；隐藏场景暂停计算与绘制。左拖旋转、右拖或 Shift＋左拖屏幕平移、滚轮缩放。可用按钮控制按下／松手／连续慢放／复位；气囊案例可直接点击模型的小拨钮，并查看阀组上、下两面。
