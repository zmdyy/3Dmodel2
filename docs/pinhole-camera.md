# 小孔成像 · 双板自由探究

## 结构与交互

- `models/pinhole-camera.html` 基于独立 V6 版本迁入。完整 GLB 模型内嵌，离线运行，器材由蜡烛、带实际开口的孔板、半透明光屏、支架与滑轨组成，取消暗箱。
- 孔板/光屏可用左键直接抓取沿滑轨移动；孔板移动时光源和光屏不动，物距、像距联动；光屏移动时只更新像距。
- 孔径 0.6～100 mm，可调圆/方/三角孔。直线传播演示倒立实像，光屏按物点光斑叠加产生几何模糊。
- 左键空白旋转，旋转角度以鼠标 `dx,dy` 的负方向更新，等同 OrbitControls 正向 rotateSpeed；右键或 Shift+左键平移、滚轮缩放。鼠标右移时可见的近侧标记向右移动。板件拖动优先于视角旋转。

## 物理模型与限制

- 几何近似 `像高/物高 = v/u`；模糊宽度约 `b=d(1+v/u)`，用光粒子示意前向传播，典型光路表示通过孔的射线。
- 模型没有进行波动光学衍射仿真，也没有声称厘米级孔仍是理想小孔成像。
