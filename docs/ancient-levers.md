# 古代杠杆工坊：资料、零件装配与物理原理

整理日期：2026年10月17日。
配套文件：古代杠杆工坊_三装置交互版.html。

## 读图结论与复原范围

三张附件涉及桔槔、踏碓和连机水碓。第一张是水碓文字说明，第二张是水碓结构图，第三张包含桔槔和踏碓。

零件类别、动力路径与基本运动关系有博物馆、科技馆和传统工艺记录支持。具体尺寸、质量、榫槽形状、轴座细节以及碓尾受拨横木的几何属于教学复原设计，不能视为某件实物的测绘值。页面不添加遮挡机构的屋顶和操作人物。

## 01 桔槔（jié gāo）

### 零件与装配

| 零件 | 装配关系与运动约束 |
| --- | --- |
| 立柱、叉架与斜撑 | 固定于地面，承受支点载荷，不跟随横杆摆动。 |
| 支点轴与轴座 | 轴线横向布置，横杆仅能绕轴转动。 |
| 长横杆 | 跨在支点两侧，本模型桶端长、配重端短。 |
| 配重石与绑绳 | 配重悬挂于短端，随端点升降，保持悬垂；绳只能受拉。 |
| 井绳、木桶 | 木桶悬于长端，绳长不变，桶保持竖直。 |
| 石砌井栏、井水 | 固定，井口留出桶沿端点圆弧产生横向位移的空间。 |

### 操作与物理原理

1. 人下拉桶端，空桶下降，同时配重上升。
2. 桶进入井中，汲水增加桶端负载。
3. 配重下降，辅助提桶；是否能自行提起取决于两侧力矩。
4. 取出水后进行下一轮操作。

力臂是支点到力作用线的垂直距离。两端重力均竖直、杆与水平夹角为 θ 时，力矩分别为：

- 配重端：τ配 = m配 g l配 cosθ。
- 桶端：τ桶 = (m桶＋m水) g l桶 cosθ。

忽略杆重、绳重和摩擦时，两侧力矩相等才可能平衡。配重不足，松手后满桶不会自行上升。配重辅助提水的能量来自此前人把它抬高时做的功，不能据此认为整个循环可以省功。

教学设定：空桶2 kg；桶端2.60 m，配重端1.25 m；配重5—32 kg，桶水0—10 kg。模型按力矩计算释放后的转动；自动演示包含人力下拉的阶段控制。汲水、取水以阶段切换表示，未模拟倾桶灌水、浮力或绳索摆动。

## 02 踏碓（tà duì）

### 零件与装配

| 零件 | 装配关系与运动约束 |
| --- | --- |
| 底架、双立柱、轴座 | 固定于地面，构成支点承重结构。 |
| 碓杆与支点轴 | 碓杆绕固定轴摆动，不发生整体平移。 |
| 短尾、踏板 | 踏板固定于短尾，脚向下施力时短尾下降。 |
| 长端、杵杆与碓头 | 刚性连接，长端随短尾下降而抬起，碓头沿圆弧运动。 |
| 石臼、谷物 | 石臼固定，内腔容纳碓头入臼时的弧线扫掠范围。 |
| 站台与扶手 | 固定于底架，帮助站稳，不随碓杆摆动。 |

### 操作与物理原理

脚踩短端，碓头抬升；松脚后，碓头及碓杆受重力驱动回落。撞击时，机械能用于谷物变形和破碎，也转化为声与内能。

本模型脚施力点离支点0.78 m，碓头横向距支点2.10 m，动力臂较短，是费力杠杆。它换来较大的碓头运动幅度，不能把“使用杠杆”一概理解为“省力”。

转动方程使用：

Iα = F脚 a cosθ − m头g(L cosθ＋h sinθ) − m杆g x重心 cosθ − cω。

其中碓头向下偏置h，转动惯量计入碓头偏心与杆的惯量。页面的 m头gΔh 仅计碓头势能，不包含整根碓杆。撞击后停止，不据此估算冲击峰值。

教学设定：碓头8—20 kg，脚向下压力100—650 N，碓杆质量12 kg。按住按钮施力，松开回落；压力不足时抬不起碓头。模型中的石质碓头是一种复原选择，各地实际碓头的材料和形状并不完全相同。

## 03 连机水碓（shuǐ duì）

### 零件与装配

| 分部 | 零件与连接 |
| --- | --- |
| 引水系统 | 固定水槽、闸门、受控水流。水流作用于轮缘叶板。 |
| 水轮 | 双轮圈、轮辐、叶板、轮毂组成刚体。轮毂与主横轴固定连接。 |
| 主轴与轴承架 | 横轴水平延伸，由两端固定轴座支承；横轴相对于轴座转动。 |
| 拨板 | 四组拨板固定于同一横轴，每组对应一根碓杆，相位错开90°。 |
| 碓尾受拨横木 | 与碓尾刚性连接，侧向伸入拨板轨迹。具体横木形状为教学设计。 |
| 碓杆、支点、碓头 | 四根碓杆各有独立固定支点，碓头随杆摆动。 |
| 石臼 | 每组一个，位置对应碓头入臼轨迹，固定于地面。 |

### 动力路径与接触过程

水流 → 叶板 → 水轮与横轴 → 错相拨板 → 碓尾 → 碓杆 → 碓头 → 谷物。

拨板不是与碓尾连接的连杆。拨板在接触阶段压下碓尾、抬高碓头；拨板越过受拨横木边缘后脱离，碓头靠重力回落。连续转动由间歇接触机构转换为碓杆摆动。

四组拨板错开相位，使舂捣分时发生。每组单拨板、轮速n rpm时，稳定运行的理论总舂次为4n次/分。真实轮速和能否带动四组负载，受水流可用功率、机械效率及负载限制。落差供水时可用 P≈ηρgQH 估算；下部受流的轮还需考虑来流速度、水流动能与具体水力条件。

本页闸门滑条只控制演示轮速，不是实际流量标定；没有模拟水动力转矩与负载耦合。碓杆自由回落使用转动力学，拨板压尾使用几何接触约束。

### 需要保留的资料差异

- 用户提供文字写“卧式水轮”，配图却是竖直轮面、水平主轴。本版按配图复原，并直接标注轮面与轴向，避免名称歧义。
- 同济大学博物馆与中国机械工程数字博物馆资料支持立式水轮、横轴和卧式碓杆的组合。
- 不同资料对连机碓创制年代和杜预的贡献表述不一致。页面不以某人“首次发明”作为教学结论。
- 苍南工艺记录有地方性结构与尺寸，不能把其具体轮径、叶片数和材料直接视为教材图装置的测绘结果。

## 可用于课堂的探究

1. 桔槔：桶水质量不变，逐渐减少配重，满桶还能自行升起吗？比较两侧力矩。
2. 踏碓：逐渐减小脚的压力，观察能否抬起碓头。为什么本例费力却仍便于劳动？
3. 踏碓与水碓：打开轨迹，确认碓头走圆弧，检查石臼需要怎样留出空间。
4. 水碓：用慢放、分步和主轴角度滑条，找出压尾、抬头、脱离和回落阶段。
5. 三装置比较：动力来源、固定支点和能量输入在哪里？自动运动为什么仍需要能量？

## 成品与验证状态

一个独立HTML内含三个装置，可旋转缩放、点击零件查看连接，支持自动演示、暂停、分步、慢放、视角切换、标注与力的开关、碓头轨迹。内嵌Three.js r165、OrbitControls和程序纹理，无外部网络依赖；声音为合成舂捣提示音。

已通过完整脚本语法、三个场景的构建和持续模拟、配重不足与充足对照、脚压力不足与充足对照、松脚回落、拨板接触几何残差、四组持续运行、力和轨迹图层逻辑检查。运行检查使用模拟DOM与渲染器，几何和转动计算使用真实Three.js代码。

尚未完成实际浏览器中的GPU渲染、遮挡、标注布局和材质视觉验收。因此本版为教学结构复原V1，不标称实物精确复刻或完整流体仿真。

## 本轮修订：单碓观察与力的显示

- 删除画面“离线 3D · 教学结构复原 V1”。
- 支点使用独立的圆点与“支点 O”，不以箭头标支点，不随力开关隐藏。本版不显示支点支持力箭头。
- 力采用浅色描边的粗箭头，渲染时不被模型遮挡，文字移到箭头末端旁。箭头是受力示意，长度未按力的数值比例绘制。
- 水碓默认单碓观察：保留一个水轮、短主轴、一个拨板、一根碓杆与石臼。四碓联动保留原错相机构。
- 单碓／四碓切换保留当前轴角度和播放状态，舂次重新统计；视角自动适配。
- 拨板压力只在接触时出现，脱离后隐藏；碓头重力持续显示。
- 仓库版位于 models/ancient-levers.html，引用共享 Three.js r165；独立下载版仍内嵌引擎，可离线打开。
- 首页封面是三种机构的矢量示意，不是实际3D场景截图。
