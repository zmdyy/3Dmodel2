# 高压锅 · 气压与安全机构

入口：`models/pressure-cooker.html`。内嵌单一 Three.js r186、TrackballControls 与全部材质代码，无外部请求，支持 file:// 双击离线运行。沿用已验收的独立课件引擎，不引入另一份 r160。

| 项目 | 本案例 |
|---|---|
| 教学目标 | 观察温度、表压和定向排气的不同表达；区分承力旋合凸耳、阻挡反转的压力销、重锤限压与备用泄压 |
| 单位与坐标 | 压力读数 kPa 表压；角度 rad；动画以秒推进。器材几何为原课件场景比例单位，非可制造尺寸 |
| 复用与规范 | 保留原课件哑光 PBR/加工细纹；核对仓库导航及字体规范。左拖自由旋转，右拖/Shift+左拖屏幕平移，滚轮缩放；单一渲染循环 |
| 连接关系 | 锅盖凸耳与锅身凸耳承力；压力销杆、下扩大头与密封垫随盖移动；挡肩固定锅身；红色按钮经滚轮压动杠杆，托叉抬重锤 |
| 状态与简化 | 时间轴共用状态驱动锅盖旋转、压力销行程、压力读数、阀门及排气。103.4 kPa 是教学工作压力示例，位移与速度有放大，非热力学/流体数值计算 |
| 气体 | 320 个固定示踪点在水面上方气相区域运动；蓝青至橙红及运动速度表达相对冷暖，不直接标定温度，不计数真实分子。金色箭头随表压缩放，青色箭头表示已打开通路中的气流 |
| 手动降压 | 按压只开阀；压力降低、金色箭头减弱；短时间保留暖色，压力销独立受余压控制 |
| 备用泄压 | 橡胶塞弹起后被罩捕获；气体从孔内上升、绕塞、由朝锅心的罩口排出；出口雾滴扩散消散。罩体透明便于观察，触发压力未标定 |
| 镜头与剖切 | 默认整机剖切；四个机构特写；任意切面方向/转角/位置；核心操作连杆保留完整；未加自动镜头 |
| 字体与局部观察 | 操作栏正文/按钮16px、标题18px、读数36px；直接缩放与机构特写；不添加无实际读数需求的独立放大窗 |

结构依据：

- Presto 原始压力销直接阻挡式锁止专利 US4162741A，第一实施例 Figures 2/4/5/14–16：https://patents.google.com/patent/US4162741A/en
- 按钮—杠杆—限压阀联动原理 US20200128996A1：https://patents.google.com/patent/US20200128996A1/en
- 原型使用说明：https://www.gopresto.com/uploads/01365.pdf

这是多项已核实原理的教学组合，不是某款产品的完整复制，也不作制造依据。密封圈未按原厂唇形剖面复刻。

## 封面与验收
