# 温度计与热膨胀 · 九种结构探究

正式入口：`models/thermometers-thermal-expansion.html`。Three.js r170、React、字体和参考图全部内嵌，可双击 HTML 离线运行。

## 教学内容

1. 实验室液体温度计与壁挂式温度计：液柱与温度刻度同步。
2. 水银体温计：狭道断口、最高值保持、甩动复位、较高体温重新接续；断口有局部特写和放大示意。
3. 双金属温度计及放大的红蓝直片：受热向低膨胀材料侧弯曲；受冷反向弯曲。
4. 远传温度计：波登管扁圆截面趋圆、自由端位移，经连杆、扇形齿轮与小齿轮传动。
5. 金属杆热膨胀：酒精喷灯加热、固定端与滑动导向、接触式测杆、齿条与指针；端面位移用彩色区及放大图表示。
6. 两种空气温度计：封闭瓶连接水平液柱；玻璃球长管浸入水槽。

## 交互与说明

左键旋转、右键或 Shift+左键平移、滚轮缩放；可切换默认、侧视、背视、剖切与局部特写。温度、液柱、形变与读数使用同一状态。玻璃球式刻度在水槽前保持高对比；壁挂式双侧 −30～50°C 数字均完整显示。

双金属片曲率、波登管形变、杆端位移及狭道放大图为教学增强；不是精密校准或原厂制造图。金属杆采用 ΔL=αL₀ΔT；喷灯热响应采用集中热容与线性散热，演示时间加速×6。玻璃球式空气温度计联立理想气体关系与液柱压强差；水槽液面近似不变。气体粒子为定性示踪。
