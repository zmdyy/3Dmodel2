# DZ47 单极断路器结构验证样机（1P / P0）

## 目的与当前状态

- 新增独立结构验证样机 `models/dz47-single-pole-prototype.html`，**暂不登记首页目录**。此版本完成用户实物审核前，不从1P扩展2P，不覆盖原先 `models/dz47-breaker.html`。
- 以典型小型断路器的热脱扣、磁脱扣、弹簧、锁扣及动静触点为基础。外形和局部机构为教学重建，**不是某厂 DZ47-63 的拆机复刻或电气工程设计文件**。
- 机构参考：[US5245302A 微型断路器触点-手柄-锁扣-弹簧装配](https://patents.google.com/patent/US5245302A/en)；[ABB Miniature circuit breakers](https://library.e.abb.com/public/a0e54ab7423d4dd0a609c0f1e0abace2/1SXP403001C0203.pdf)。专利的弹簧和锁扣连接原理与本样机相近，具体形状和尺寸不宣称一致。

## 主要连接关系

| 编号 | 上游零件/支点 | 下游零件/支点 | 连接种类和验收 |
|---|---|---|---|
| E1 | 上接线铜端 | 电磁线圈上引出端 | 永久金属导电连接（两点坐标相同，铜色连接片可见） |
| E2 | 电磁线圈下引出端 | 静触点铜排 | 串联导电，两点相接、非悬空 |
| E3 | 静触点 | 活动触点 | 合闸时银触点两面相接，断开时形成空气间隙 |
| E4 | 活动触点臂根部 | 柔性编织铜带 | 电连接但允许触点臂转动 |
| E5 | 柔性编织铜带 | 双金属片自由端 | 电连接，双金属片的下固定端经铜排连下端子 |
| M1 | 底座固定轴承 | 活动触点臂 | 销轴转动，固定轴不跟随臂旋转 |
| M2 | 底座固定钩 | 拉伸弹簧 | 固定锚点，不能位移或转动 |
| M3 | 拉伸弹簧 | 活动触点臂固定挂销 | 活动锚点跟随触点臂运动，端点距离决定弹簧伸长量 |
| M4 | 底座锁扣销轴 | 脱扣锁扣与活动臂卡舌 | 正常合闸时抵住卡舌，热/磁顶杆动作后转离 |
| M5 | 手柄固定轴 | 操作杆 | 由固定长度的销接连杆回推活动臂以便复位 |
| M6 | 双金属片自由端 | 热推杆下端 | 弯曲到接触位置才推动推杆，然后解锁 |
| M7 | 磁铁芯 | 锁扣释放端 | 短路时铁芯沿导向线滑动，顶杆到接触位置才解锁 |

## 完成的模拟与程序校验

- 浏览器逻辑模拟中，模拟渲染器替代 WebGL，仅检验几何构建、事件响应和运动状态；所有页面交互操作未捕获 JS 异常。
- 初始结构坐标自检：触点中心在 XY 面距离 `0.00563` 单位；触点两面的 Z 间距为零；锁扣鼻端至卡舌中心 `0.0210`；动触点扫描与灭弧室包围界的最小边距 `0.0651`；线圈引出两端与铜片接口误差小于 `1e-12`；销接连杆长度始终 `0.700`。
- 物理近似中，锁扣闭合时弹簧储能约 `1.176` 教学单位；释放分闸后约 `0.366`；由两端弹簧位移计算拉力与转矩，触点受转矩加速，最终受到机械开闸限位。
- 短路时磁推动件接近锁扣释放耳后才执行释放；过载时双金属片自由端到达热推杆才执行释放。
- 通过正常操作、短路、过载、手动断开、手柄复位完整模拟流程。
