# 弹簧测力计 · 三种结构（V8）

入口：`models/spring-force-meters.html`，分类：力学实验。

## 结构及边界

- 甲：圆筒式 5 N，分度值 0.1 N。深蓝外筒固定，浅米黄长刻度内管随弹簧下端及挂钩移动，以红色固定下沿读数；数字放大、主副刻线分级加粗。类型依据育星仪器 14005 圆筒测力计说明，内部支承、连接和尺寸为教学推定，不能宣称与用户早期图片逐件一致。
- 乙：条形盒式 10 N，分度值 0.2 N。按用户拆解确认的连接关系：上圆环与盒内横杆一体；弹簧上端直接挂横杆，下端接冲压金属长片；指示片固定于长片折弯部，经固定刻度板中央通槽露出；独立 S 钩穿接长片底孔。无虚构黑色调零盘或圆形主拉杆。形状尺寸按照片比例估计，并未实测标定。
- 丙：开放式 5 N，分度值 0.1 N，直接观察弹簧、传力杆与指针。传力杆与下挂钩连续成型；接头和导向座细节仍待原始实物图片核对。类型参考育星仪器 14008 平板测力计，非指定品牌精确复刻。
- 同一拉力驱动弹簧、活动件、挂钩、Canvas 刻度对应位置与 SVG 特写。三款对照范围 0–5 N；单独选择乙款可到 10 N。满量程显示行程为 135 个模型单位，不是实测伸长量；未给出虚构劲度系数或精密仪器误差。
- 分解仅移开固定壳体和刻度板，传力链保持连接；侧壁剖切为移除遮挡部件的教学视图。

## 显示、操作与依赖

- Three.js r160、PMREM 程序摄影棚环境、PBR 材质；Canvas 1024×4096 刻度板与 2048×4096 圆筒刻度，配独立 SVG 读数视图。
- 本地公共库 `../shared/vendor/three-r160.min.js`，以及 `material-finish.js`、`navigation-style.js`。刻度材质明确退出旧化，避免纹理与可读性被改变。无 CDN 请求。
- 左拖旋转（模型跟随拖动方向）、右拖/Shift 左拖按相机屏幕方向平移、滚轮缩放；双指平移缩放。自动取景覆盖加载行程，手动操作后停止自动取景，点击全景恢复。
- 首页仅打开时加载 iframe，返回后卸载；页面离开时停止动画并释放 WebGL 上下文。
- 独立离线单文件已另行交付；仓库版需连同共享目录使用，可通过静态服务或 GitHub Pages 打开。
