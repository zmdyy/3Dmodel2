# 三维案例鼠标操作约定

所有三维视图遵循同一套鼠标手势。底层实现仍包含 OrbitControls、Three.js 自写控制器和原生 WebGL 控制器。

| 操作 | 行为 |
| --- | --- |
| 左键拖动视图 | 绕观察中心旋转；面向观察者的一侧随鼠标方向转动 |
| 右键拖动 | 在当前屏幕平面内平移；模型跟随鼠标移动 |
| Shift＋左键拖动 | 与右键平移相同 |
| 滚轮 | 缩放观察距离或正交相机视野 |

旋转存在各案例的俯仰角限制，到达限制后停止继续转动。直接用普通左键拖动可交互部件时，保留原有的调焦、滑片、水位等实验操作；右键或 Shift＋左键优先用于视图平移。平移改变观察中心和相机的位置，不改变装配关系或实验参数。

`shared/navigation-style.js` 提供 OrbitControls 配置和屏幕平移函数。新案例可调用 `Navigation3D.configureOrbit(controls)`；自写 Three.js 控制器用 `Navigation3D.isPan(event)` 判断手势，再调用 `Navigation3D.pan(camera, target, canvas, dx, dy)`，并在下一帧按更新后的 target 同步相机位置。平移量按视口高度和实际投影计算，使用相机当前的右向、上向基向量。

2026-10-18 盘点覆盖 models 下全部 34 个案例，包含 32 个三维案例及 2 个二维示意（核电站、光的反射与折射）。电动机页面另含通电导体棒、手动换向、换向器 3 个内嵌子实验，也应用同样的鼠标约定。二维图中的实验拖动保持原有含义。
