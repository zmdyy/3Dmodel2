# 不同燃料的热值 · 双灯探究实验

## 教学目标与实验条件

学生调整两杯共同的水质量、初温和每种燃料的目标消耗质量，比较酒精与煤油完全燃烧后的水温变化。默认两灯各装40 g燃料，达到相同的目标消耗质量后盖帽熄火；不是将整灯烧干。燃烧速率允许不同，不用相同时间替代相同燃料质量。

燃料量不按“避免沸腾”限制，不提前提醒失败条件。水到100 ℃后继续吸热用于汽化，学生观察平台和水量变化后可重新试验；页面不自动给出比较结论。重新试验自动保留上一轮曲线。

- 模型参数：酒精热值3.0×10⁷ J/kg、煤油4.6×10⁷ J/kg；传给水的效率共同设为35%。
- 温度计算：`Q水=4.2 m水 ΔT`（质量g，能量J）；沸腾后采用2260 J/g汽化潜热。标准大气压；忽略杯体吸热和停止加热后的散热。
- 装置几何沿用源案例归一化显示坐标，不能直接当作以m为单位的公共器材接口拼接。物理质量g、时间s、能量J，导航角度rad。
- 燃料的蓝/橙色是组别示踪色，不表示燃料真实颜色。燃烧速率为演示设定。
