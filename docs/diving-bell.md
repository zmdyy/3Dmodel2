# 潜水钟：资料、零件装配与物理原理

配套页面：[潜水钟 · 空气与水压](../models/diving-bell.html)。仓库版复用本地 Three.js r165 与 OrbitControls，经 GitHub Pages 或静态 HTTP 服务打开；单文件下载版仍内嵌引擎，支持离线打开。

本案例比较两种底部敞口潜水钟：只携带初始空气的简易型，以及由水面管路补气的供气型。它们都不是保持一个标准大气压的密闭潜水器。供气版参考湿式潜水钟的管路与承重关系，简易版参考历史开口钟体；不是某一件设备的测绘复刻。

## 一、共同零件与装配

| 零件 | 连接、密封与作用 |
| --- | --- |
| 圆筒钟体、封闭顶盖 | 顶部和侧壁气密，底部敞口。顶盖与筒身通过法兰、垫片和螺栓连接；剖视只移除观察扇区，物理计算仍认为壳体完整。 |
| 口沿、低位配重、支脚 | 配重固定在下部，增加向下的重力并降低重心；开口处没有封底玻璃或密闭地板。支脚外置，不封堵水路。 |
| 吊耳、吊索、卷扬架 | 吊耳连接承重结构；钢索向上连接水面吊装机构。供气软管独立连接，不承担钟体重量。 |
| 观察窗与压紧圈 | 侧面窗口用透明窗片、密封垫和螺栓压圈组成。完整外观下的窗口为结构示意，剖视展示内部空气和水。 |

## 二、两种模式的差异

| 模式 | 额外零件与工作过程 |
| --- | --- |
| 无持续供气 | 钟口刚接触水面时捕获一团空气。下潜使其压缩、内部水位升高；上浮使其膨胀，空气充满钟体后可由下口逸出。模型不设置呼吸耗气和漏气。 |
| 水面持续供气 | 水面压缩气源／储气罐 → 调压与截止阀 → 压力表 → 软管 → 钟体穿壁接头与止回阀 → 钟内进气口。加气可使内部水位下降，充满后余气从下口冒泡。停止供气且深度不变、系统无漏气时，水位保持稳定。 |

湿式潜水钟实物还可配备应急气瓶、照明、通信、热水管路等。本页只简化呈现与水压、存气及承重有关的部件；储气罐容量、泵性能和软管压降不作工程计算。

## 三、压强、体积与气体量

设钟口深度为 D，内部水面高于钟口 y，内部水面的深度是 dᵢ = D − y。忽略空气自身的压强梯度，静水平衡给出：

p空气 = p₀ + ρg(D − y)

这里 p₀ = 101.325 kPa，g = 9.81 m/s²。全部气体计算使用绝对压强；表压为 p空气 − p₀。水面处开始捕获空气，初始条件 p₀、V₀。无补气、无漏气、同温时：

p空气 × V空气(y) = p₀ × V₀

本模型有圆筒腔和椭球形顶腔。内半径 R = 0.85 m，筒高 Hc = 1.90 m，顶腔高 Hd = 0.45 m。总内高2.35 m，总容积 V₀ = πR²(Hc + 2Hd/3)，约4.993 m³。水位通过上述压强与实际腔体体积联立求解，未把有顶腔的钟体错误当成等截面圆柱。

供气时气体量发生变化，不能继续固定使用初始 p₀V₀。程序用 S 表示气体在水面压强、相同温度下的等效体积，求解 p空气V空气 = p₀S。气源压力不足时停止进气；止回阀阻止回流。钟内满气时 p空气约等于钟口处水压，多余气体由敞口排出。

停止供气不等于立刻进水。本模型在恒定深度下既不漏气也不耗气，所以关阀后水位保持；随后再下潜，空气才因压强上升而继续压缩。真实人员呼吸、气体成分变化及换气需求不在本模型内。

## 四、浮力与吊装

不能用整个外包络体积始终计算浮力，因为敞口钟内已进水的部分不排开外部水。本页估算 F浮 = ρg(V浸没壳材＋V水下空气空间)。空气空间压缩，浮力随之减小；补气排水，浮力增加。位于水面之上的部分不计入排水体积。

壳体、框架、配重总质量取教学值7000 kg，浸没固体体积约0.90 m³（分壳体及下部结构按高度计入）。钟体位置由卷扬控制，不计算自由升沉、吊索张力变化、船体稳定性或水动力阻力。配重与吊装示意不作为实际设备的结构设计依据。

## 五、观察任务

1. 无供气模式从钟口深度0 m开始下潜：记录内部水面深度、空气体积和绝对压强。检验 pV 是否保持不变。
2. 同样钟口深度，比较淡水与海水；为什么海水中空气被压缩得略多？
3. 固定深度，启动供气，观察水位下降与空气体积增大；为什么钟内压力并不等于较高的气源压力？
4. 空气充满后继续供气，观察下口冒泡；停止供气，水位是否立刻上升？再下潜比较。
5. 比较 p—V 图：固定气体量的过程可沿等温曲线；加气时属于另一组气体量，不应把整个供气过程强套在同一条曲线上。

## 六、检索来源与证据边界

1. [Kenyon College：Diving Bell](https://physics.kenyon.edu/EarlyApparatus/Pneumatics/Diving_Bell/Diving_Bell.html)。历史教学装置、开口钟与下潜进水压缩过程。
2. [Science Museum Group：Halley潜水钟模型](https://collection.sciencemuseumgroup.org.uk/objects/co2184/model-of-halleys-diving-bell)。顶端吊环、阀、采光窗与历史补气方式。Halley使用空气桶补气，不能把本页水面软管供气说成其原始结构。
3. [Western Australian Museum：Oceaneering Wet Bell](https://museum.wa.gov.au/immerse/highlights/oceaneering-wet-bell)。湿式潜水钟的空气空间、脐带管路及应急气源。
4. [SMP：Diver Wet Bell System](https://www.smp-ltd.com/smp-diver-wet-bell-system)。钟体、观察窗、内部控制、气体分配、吊装与管材；本页不照搬其工作深度或设备尺寸。
5. [SMP：Wet Bell Launch and Recovery Systems](https://www.smp-ltd.com/blog/post/wet-bell-launch-and-recovery-systems-lars)。顶罩、卷扬与独立吊装系统的可见结构。
6. [NOAA：Pressure and depth](https://oceanservice.noaa.gov/facts/pressure.html)。水压随深度增加。
7. [NASA Glenn：Boyle’s Law](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/boyles-law/)；[气体状态方程](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/equation-of-state/)。固定温度、气体量的 pV 关系及气量改变时的关系。

资料检索于2026-10-17。公开资料支持零件类别、一般连接关系与基本原理；本页钟体比例、法兰细节、软管路径、进气性能和水面吊架为教学设计。程序纹理与几何自行生成，参考照片未嵌入页面。

模型采用准静态、近似等温的理想气体与静水模型；忽略溶解、表面张力、气体温差以及波浪与晃动对压强的影响。外海波浪和钟内微弱涟漪只作视觉展示，计算始终使用平均海面与平均内部水面。演示速度不代表真实下潜操作参数。两种模式均为开口型，不包含密闭式潜水钟及保压转运过程。

## 交互与验证状态

- 独立下载版HTML内嵌3D引擎与程序材质；仓库版复用 shared/vendor/three-r165/ 本地模块，无CDN依赖。可旋转缩放、切换剖视与完整外观、近看或查看水面吊装全系统、开关标签与气体粒子、点击零件查看装配说明。
- 两种模式同一腔体几何与物理参数；切换时保留深度、重新捕获初始气体量，便于同深度比较。
- 可自动下潜／上浮、暂停、手动调深度、切换淡水与海水；供气模式可调供压与折算供气量，并开关供气。
- p—V图像与表格共享同一物理状态，可记录并导出CSV。气体粒子数量和冒泡为定性示意，不作微观或排气计量。
- 检查通过：124组深度／密度状态的气体与静水方程残差；供气排水、满气逸出、停止供气后稳定、供压不足与中间供压限制、上浮排出多余气体。
- 使用真实Three.js构建几何，模拟DOM与渲染器执行双模式、剖视、相机、标签、记录和图像逻辑。实际浏览器GPU渲染与视觉遮挡尚未验收。
- 本模型是课堂物理演示，不用于潜水作业参数、生命支持时间或压力容器设计。


## 微缩海景更新（2026-10-17）

- 方形水体剖面约40 × 36 m；水下尺寸保持米制，钟口可降至30 m。后侧小岛、沙滩、树木、两栋小屋和栈桥采用景观化简；不作为实际岸线测绘。
- 海面采用三组叠加波形和随时间变化的近岸泡沫，海床有坡地、沙纹、凹地、岩石和稀疏水草。正面与右侧水体使用低透明度，便于看见钟体和海底。
- 中央落点保持平整，海床高度−30.42 m；支脚最低点在钟口下方0.42 m。根据支脚接触采样限制下降深度，触底停止，可继续上浮。深度尺、钟口深度、内部水面深度和支脚距底读数共同提供距离参照。
- 默认从水面开始、显示微缩全景；可切换近看或正视剖面。近景跟随钟体深度，距海底4 m内逐渐扩大取景。
- 气体粒子默认显示，按实际播放时间持续运动；暂停升降和供气时仍运动。在钟体内壁、顶部和平均内部水面反射，界面移动时重新约束到空气区域。封存气体固定显示90粒，补气时按等效气量增加，最多360粒；这不是实际分子数量或速率。
- 桌面锁定整页高度，仅右侧控制栏滚动；窄屏改为整页滚动，取消侧栏内部滚动。资料与装配说明单独弹窗。
- 新增逻辑检查通过：下潜越过触底位置时截停、所有支脚采样不穿入海床、触底后上浮；暂停状态下600帧粒子持续运动并保持在气腔范围；粒子数量随固定气量保持不变，波浪时钟继续推进。
- 已用真实几何作软件投影检查整体构图；该检查不覆盖着色器、浏览器文字遮挡和实际GPU效果。实际浏览器画面仍需打开HTML验收。
