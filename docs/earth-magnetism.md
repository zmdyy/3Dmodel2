# 地球磁场 · 指南针探究

支持点击地球或拖动指南针改变经纬度。地表指南针在当地切平面内沿磁场水平分量排列；空间磁针可调高度，沿完整三维磁场排列。支持整体、靠近磁针、半透明地球、等效磁体和磁棒内外磁感线开关。

保留 11° 倾斜磁轴。等效磁体不是地球内部的真实磁棒，也不代表当前实测地磁场。使用均匀磁化有限条形磁体的表面束缚电流等效，64 层矩形电流环、256 条有限直线电流段按 Biot–Savart 定律求和。磁感线用 RK4 沿同一 B 场追踪，磁针与箭头也使用这一场；无磁力线手工连线。磁棒外 N→S、磁棒内 S→N；地球表面不是等效磁棒的边界。

8 条展示回路全部穿过两端并闭合，线段切向与场方向点积最低 0.9999995。已在实际 Chromium 检查 216 组地表与空间磁针方向、内部开关自动打开半透明地球、脚本错误和 1280×720 控制区。教学中的磁极附近会提示水平指向不确定。

复用 Three.js r160、共享哑光材质与导航。地球贴图复用 shared/textures/earth-atmos-r144.jpg（Three.js 示例地球纹理）；教学磁极色不加旧化。全屏、左拖旋转、右拖或 Shift＋左拖平移、滚轮缩放与仓库一致。封面取自实际运行场景。
