# 光的折射 · 一池两世界

| 项目 | 说明 |
|---|---|
| 教学目标 | 在同一镜头比较折射前后的视位置，沿光路识别折点和法线。用叉鱼比较瞄准偏差，再观察铅笔的实物与虚像。 |
| 引擎与单位 | 采用仓库本地 Three.js r160。海湾以水面为竖直坐标零点，观察深度用米，时间用秒，镜头内部角度用弧度。水杯用模型单位表示。 |
| 连接与状态 | 水面观察的光路从真实物点出发，经界面到达观察眼点。海床与水下石块共用折射渲染。铅笔的光路、实体笔杆和虚像轮廓共用杯体、铅笔和观察点。 |
| 物理模型 | 界面折射使用斯涅尔定律。关闭折射是保持场景条件的直线路径对照。杯口视图追踪水面折射，隔杯壁视图示意水、玻璃和空气之间的折射。虚像轮廓是按观察方向回延所得的教学近似。 |
| 镜头与布局 | 参照 `camera-navigation@1.0.0` 的鼠标与双指约定，沿用本案例穿越水面的镜头约束。场景页签、模型和操作栏同框。窄屏将操作栏放在模型下方，操作栏独立滚动。 |
| 局部观察 | 通过滚轮或双指缩放进入近景，光路与文字用 SVG 和 HTML 叠加。玻璃杯沿用本案例已有材质与光路。 |
| 封面 | 使用默认海岛场景的实际 WebGL 渲染，隐藏界面后截取 960 × 540 画面。 |
